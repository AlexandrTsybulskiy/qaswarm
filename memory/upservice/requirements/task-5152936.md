На личном Web-дашборде сотрудник видит виджет «Мои трудозатраты»: суммы Фактических трудозатрат за сегодня, текущую календарную неделю и текущий месяц (только свои записи) в часах и минутах, плюс график динамики Фактических трудозатрат по датам с фильтром Неделя (по умолчанию) или Месяц. При отсутствии записей — нулевые суммы и пустое состояние графика.

## Testable

- Открыть личный дашборд Web под текущим сотрудником → отображается виджет с суммами Фактических трудозатрат за сегодня, за текущую неделю и за текущий месяц
- У текущего пользователя есть записи Фактических трудозатрат → значения в виджете показаны в часах и минутах
- Открыть виджет с данными → график показывает динамику Фактических трудозатрат по датам; активен фильтр «Неделя» (= текущая календарная неделя)
- На графике выбрать период «Месяц» → отображаются Фактические трудозатраты текущего календарного месяца по датам
- На графике снова выбрать «Неделя» → отображаются Фактические трудозатраты текущей календарной недели по датам
- Пользователь A внёс Фактические трудозатраты; пользователь B открывает свой виджет → записи A не входят в суммы и график B
- У текущего пользователя нет записей Фактических трудозатрат за сегодня, неделю и месяц → суммы равны нулю, график в пустом состоянии
- Есть несколько записей Фактических трудозатрат текущего пользователя с начала текущего дня → сумма «сегодня» равна сумме их продолжительностей
- Есть записи текущего пользователя с начала текущей календарной недели (включая сегодня) → сумма «неделя» равна сумме их продолжительностей
- Есть записи текущего пользователя с первого дня текущего месяца (включая сегодня и неделю) → сумма «месяц» равна сумме их продолжительностей
- У задачи задана только плановая оценка (`estimation`), без записей Фактических трудозатрат текущего пользователя → эти минуты не входят в суммы и график виджета
- Текущий пользователь внёс несколько записей Фактических трудозатрат в разные дни выбранного периода графика → на графике видна динамика по датам этих записей
