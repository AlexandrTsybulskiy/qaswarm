Пользователь передаёт **ИИ-сотруднику** файл с контактами в **произвольной структуре** (без подготовки по шаблону Upservice). ИИ-сотрудник разбирает данные, сопоставляет поля с полями контакта Upservice, приводит к актуальному формату массового импорта, запрашивает уточнения при неоднозначности, показывает результат подготовки и после **подтверждения** создаёт контакты в рамках своих прав, затем сообщает итог импорта. Повторный импорт после частичной ошибки не дублирует уже созданные контакты.

## Testable

- Пользователь передаёт ИИ-сотруднику файл с контактами, не приведённый к шаблону Upservice → ИИ-сотрудник принимает файл и обрабатывает его без требования предварительной подготовки по шаблону
- ИИ-сотрудник получил файл с контактами в произвольной структуре → определяет структуру данных и сопоставляет исходные поля с существующими полями контакта Upservice
- ИИ-сотрудник выполнил сопоставление полей → преобразует данные к актуальному формату массового импорта, включая обязательные поля и допустимые значения
- В исходных данных отсутствует значение для поля → ИИ-сотрудник не придумывает отсутствующие данные
- Сопоставление исходного поля с полем контакта Upservice неоднозначно → ИИ-сотрудник запрашивает уточнение у пользователя
- ИИ-сотрудник подготовил данные к импорту → предоставляет результат подготовки и запрашивает подтверждение перед массовым созданием контактов
- Пользователь подтвердил массовое создание → ИИ-сотрудник создаёт контакты с соблюдением своих прав
- Импорт завершён; среди записей есть успешно созданные → ИИ-сотрудник сообщает о успешно созданных записях
- Импорт завершён; среди записей есть пропущенные → ИИ-сотрудник сообщает о пропущенных записях
- Импорт завершён; среди записей есть неуспешные → ИИ-сотрудник сообщает о неуспешных записях с причинами
- После частичной ошибки пользователь повторно импортирует тот же набор данных → уже успешно импортированные контакты не создаются повторно
