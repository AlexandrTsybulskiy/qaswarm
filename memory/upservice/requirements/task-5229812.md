В «Календаре встреч» при активной синхронизации с Google Calendar показывать не только задачи-встречи Upservice (`kind: meeting`), но и события Google владельца (Event, Task, Out of office, Focus time, Working location, Appointment schedule), в том числе из смерженных/дополнительных календарей аккаунта. Google-события без задачи Upservice визуально отличаются от встреч Upservice, не создают задачу автоматически и открываются в read-only просмотре деталей; встречи Upservice сохраняют текущее поведение клика и синхронизацию с Google Event.

## Testable

- У сотрудника с активной синхронизацией Google Calendar открыть «Календарь встреч» → в сетке видны события типов Event, Out of office, Focus time, Working location (и при наличии — Google Task, Appointment schedule), а не только задачи-встречи Upservice.
- В подключённом Google-аккаунте есть события в смерженном/дополнительном календаре владельца → эти события отображаются в сетке календаря встреч.
- Переключить представления День / Неделя / Месяц (там, где уже показываются встречи) → Google-события из scope остаются видимы в сетке.
- В сетке есть встреча Upservice (`kind: meeting`) и Google-событие без задачи Upservice → встреча Upservice отображается в оранжевом стиле (как сейчас); Google-событие — в отличном от оранжевого стиле и без аватара исполнителя Upservice.
- На карточке Google-события в сетке → видны минимум название, время (или признак «весь день»), тип/источник (Google и имя календаря при наличии).
- Специальные типы Google (Out of office / Focus time / Working location / Task / Appointment schedule) присутствуют в сетке → тип читается по стилю или метке (различимы между собой и от встречи Upservice).
- Google-событие пересекается по времени со встречей или другим событием → пересечение слотов отображается визуально так же, как для встреч (занятость видна).
- Клик по встрече Upservice в сетке → открывается карточка задачи/встречи Upservice (как сейчас).
- Клик по Google-событию без задачи Upservice → открывается read-only просмотр деталей (название, время, тип, календарь-источник); задача Upservice не создаётся.
- После появления в календаре Google-событий типов OOO / Focus / Working location / Event без задачи Upservice открыть список задач → новые задачи Upservice по этим событиям не созданы.
- Существующая двусторонняя синхронизация встреч Upservice ↔ Google Event → продолжает работать; Google-события из scope не ломают отображение уже синхронизированных встреч.
