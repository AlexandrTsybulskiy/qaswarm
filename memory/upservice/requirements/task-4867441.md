Интеграция с Legat при заполнении контрагента становится опциональной: пользователь может указать компанию вручную, не подтягивая данные из поиска. Если в поле «Компания» введён текст и компания из подсказок после «Найти» не выбрана, поле считается заполненным и создаётся компания с введённым значением. Выбор компании из результатов «Найти» оставляет текущее поведение системы.

## Testable

- В поле «Компания» ввести текст и завершить создание, не нажимая «Найти» и не выбирая компанию из предложенных → поле «Компания» считается заполненным; создаётся компания с введённым значением.
- В поле «Компания» ввести текст, нажать «Найти» и выбрать компанию из предложенных → применяется текущее поведение системы (выбранная из списка компания, а не новая запись только по введённому тексту).
