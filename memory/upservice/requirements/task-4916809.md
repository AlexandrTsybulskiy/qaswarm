В CRM-воронке в режиме **канбан** пользователь видит суммы стоимости лидов по каждому этапу и итого по всей воронке. Суммы считаются по полю **Сумма** лида, конвертируются в выбранную валюту через **ExchangeRate-API** и отображаются с символом валюты (или сокращённым кодом, если символа нет). На панели канбана добавляется выпадающий список **«Валюта»** с поиском; выбор валюты сохраняется **для текущего пользователя**. Макет (Figma): строка **«Найдено N лидов на сумму X …»**, селектор **«Валюта»**, сумма по колонке (например **2560 ₽**) под заголовком этапа, поле суммы на карточке лида.

## Testable

- Пользователь открывает CRM-воронку в режиме **канбан** → под названием каждого этапа отображается сумма поля **Сумма** лидов на этом статусе в выбранной валюте
- На этапе «Новое обращение» два лида с суммами **1000 ₽** и **1560 ₽**; пользователь открывает канбан → под названием этапа отображается сумма **2560** с символом или кодом валюты
- В верхней части канбана отображается строка **«Найдено N лидов на сумму X <символ или код валюты>»**, где **N** — число лидов воронки, **X** — сумма поля **Сумма** по всем лидам воронки в выбранной валюте
- В воронке **5** лидов на общую сумму **10 000 ₽**; пользователь открывает канбан без фильтров → вверху отображается **«Найдено 5 лидов на сумму 10 000 ₽»** (или эквивалент в выбранной валюте)
- Пользователь применяет фильтр, отбирающий подмножество лидов → суммы **по этапам** и **итого по воронке** пересчитываются только по отфильтрованным лидам
- На канбане доступен выпадающий список **«Валюта»** с **поиском** по названию валюты
- Пользователь открывает список **«Валюта»** → в начале списка идут валюты **RUB, USD, EUR, CNY, KZT, BYN, ZAR, MYR, UZS, AMD, PHP, KES**, затем остальные из общего справочника (~165 валют)
- Пользователь **впервые** открывает канбан (нет сохранённого выбора) → по умолчанию выбрана **USD**; суммы отображаются в USD
- Пользователь выбирает валюту **EUR** в списке **«Валюта»** → суммы по этапам и итого пересчитываются в **EUR**
- Пользователь **A** выбирает **EUR**; пользователь **B** в том же воркспейсе открывает канбан → у пользователя **B** остаётся **его собственный** выбор валюты (не подставляется EUR пользователя A)
- Пользователь выбирает **RUB**, обновляет страницу и снова открывает канбан → выбрана **RUB**
- Лид на этапе группы **new** или **in progress** с суммой в **USD**; пользователь выбирает отображение в **RUB** → сумма конвертируется по курсу **на текущую дату**
- Лид на **завершённом** этапе с суммой в **USD**, перемещён на этот этап **вчера**; пользователь выбирает **RUB** → сумма конвертируется по курсу **на дату перемещения** на завершённый этап
- Лид в **USD** на активном этапе; пользователь выбирает **RUB** **сегодня** и повторно открывает канбан **завтра** без смены этапа → сумма лида пересчитывается по курсу **завтрашней** даты
- Конвертация **USD → RUB** для сумм на канбане соответствует курсу **ExchangeRate-API**
- Конвертация **USD → BYN** для сумм на канбане соответствует курсу **ExchangeRate-API**
- Конвертация **USD → EUR** для сумм на канбане соответствует курсу **ExchangeRate-API**
- Конвертация **BYN → RUB** для сумм на канбане соответствует курсу **ExchangeRate-API**
- Конвертация **BYN → USD** для сумм на канбане соответствует курсу **ExchangeRate-API**
- Конвертация **BYN → EUR** для сумм на канбане соответствует курсу **ExchangeRate-API**
- Конвертация **RUB → USD** для сумм на канбане соответствует курсу **ExchangeRate-API**
- Конвертация **RUB → BYN** для сумм на канбане соответствует курсу **ExchangeRate-API**
- Конвертация **RUB → EUR** для сумм на канбане соответствует курсу **ExchangeRate-API**
- Конвертация **EUR → RUB** для сумм на канбане соответствует курсу **ExchangeRate-API**
- Конвертация **EUR → BYN** для сумм на канбане соответствует курсу **ExchangeRate-API**
- Конвертация **EUR → USD** для сумм на канбане соответствует курсу **ExchangeRate-API**
- В строке **«Найдено N лидов на сумму X»** отображается **символ** выбранной валюты
- В сумме **по столбцу** этапа отображается **символ** выбранной валюты
- На **компактной** карточке лида на канбане отображается **символ** валюты суммы
- На **развёрнутой** карточке лида отображается **символ** валюты суммы
- Для валюты **без символа** в раскладке → в строке итого, сумме по столбцу и на карточке лида отображается **сокращённое название** валюты вместо символа

## Gaps

- В `entities/` и `catalog/api.md` нет карточек CRM, лидов, воронок, поля **Сумма** и эндпоинта валют; `entities: none`. Проверка UI-only / API-unknown для CRM-ресурсов.
- Точный перечень **завершённых** стадий и граница групп **new** / **in progress** не детализированы в тикете.
- Допустимая погрешность конвертации ExchangeRate-API и поведение при недоступности API не описаны.
- Поведение при пустой воронке, этапе без лидов, лиде без заполненного поля **Сумма** не описано.
- Форматирование чисел (разделители тысяч, знаки после запятой) не зафиксировано.
- Счётчик **N** лидов в строке итого реализован в другой story; здесь проверяется только согласованность **X** и сумм по этапам с отфильтрованным набором лидов.
