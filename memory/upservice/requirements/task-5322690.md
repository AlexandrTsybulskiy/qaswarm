ИИ-сотрудник, который является оператором уже подключённого внешнего канала, по входящему сообщению во внешнем чате сам решает — создавать ли тикет — по своей существующей памяти (запись в справочнике и сохранённые правила памяти), без отдельного правила автоматизации и без нового экрана. Если в памяти указано создавать тикеты по определённым обращениям и сообщение к ним относится — создаётся тикет; контакт и канал тикета берутся из чата и входящего сообщения. Если сообщение не подходит под обращения из памяти, в памяти нет такой инструкции или ИИ-сотрудник не оператор канала — тикет этим ИИ-сотрудником не создаётся. Несколько ИИ-операторов одного канала действуют независимо, каждый по своей памяти.

## Testable

- К чату контакта подключён внешний канал; ИИ-сотрудник указан оператором этого канала; в его памяти записано: в каналах, где он оператор, создавать тикеты по обращениям о поломке оборудования; контакт присылает входящее сообщение «Сломался принтер, не печатает» → ИИ-сотрудник создаёт тикет
- К чату контакта подключён внешний канал; ИИ-сотрудник указан оператором этого канала; в его памяти записано создавать тикеты по обращениям о поломке оборудования; контакт присылает «Сломался принтер, не печатает»; ИИ-сотрудник создал тикет → контакт созданного тикета взят из этого чата
- К чату контакта подключён внешний канал; ИИ-сотрудник указан оператором этого канала; в его памяти записано создавать тикеты по обращениям о поломке оборудования; контакт присылает «Сломался принтер, не печатает»; ИИ-сотрудник создал тикет → канал созданного тикета взят из этого чата и входящего сообщения
- К чату контакта подключён внешний канал; ИИ-сотрудник указан оператором этого канала; в его памяти записано создавать тикеты по обращениям о поломке оборудования; контакт присылает входящее сообщение «Спасибо!» → тикет не создаётся
- К чату контакта подключён внешний канал; ИИ-сотрудник не указан оператором этого канала; в его памяти записано создавать тикеты по обращениям о поломке оборудования; контакт присылает «Сломался принтер, не печатает» → этот ИИ-сотрудник тикет не создаёт
- К чату контакта подключён внешний канал; ИИ-сотрудник указан оператором этого канала; в памяти ИИ-сотрудника нет инструкции создавать тикеты по таким сообщениям; контакт присылает «Сломался принтер, не печатает» → тикет не создаётся
- Операторами одного внешнего канала указаны два ИИ-сотрудника; в памяти первого записано создавать тикеты по обращениям о поломке оборудования; в памяти второго такой инструкции нет; контакт присылает «Сломался принтер, не печатает» → первый ИИ-сотрудник создаёт тикет
- Операторами одного внешнего канала указаны два ИИ-сотрудника; в памяти первого записано создавать тикеты по обращениям о поломке оборудования; в памяти второго такой инструкции нет; контакт присылает «Сломался принтер, не печатает» → второй ИИ-сотрудник тикет не создаёт
