Пользователь отправляет AI-сотруднику текстовые файлы (docx/doc, pdf, xls/таблицы) в чат сущности, к которому у AI уже есть доступ. AI автоматически открывает и обрабатывает содержимое через LLM, подтверждает ознакомление с каждым файлом и в рамках того же чата отвечает на вопросы по содержимому через кратковременную память. Краткое саммари выдаёт только по отдельному запросу (в т.ч. отдельно по каждому файлу при нескольких вложениях). При неподдерживаемом типе, повреждённом файле или неясном контексте AI сообщает отправителю и не начинает обработку.

## Testable

- Пользователь отправляет AI-сотруднику поддерживаемый текстовый файл (docx/doc, pdf или таблица/xls) в чат → AI автоматически открывает файл и обрабатывает содержимое с использованием LLM без ручного запуска анализа.
- Анализ поддерживаемого файла завершён успешно → AI подтверждает ознакомление с этим файлом в чате.
- После успешного ознакомления пользователь в том же чате спрашивает о содержимом файла (без явного запроса саммари) → AI отвечает по содержимому через кратковременную память чата.
- Пользователь отдельно в том же чате просит краткое саммари по файлу → AI выдаёт краткое саммари; без такого доп. запроса саммари не считается обязательным ответом на факт ознакомления.
- AI получает файл неподдерживаемого типа или повреждённый файл (или контекст неясен) → AI сообщает отправителю об ошибке/ограничении и не начинает обработку содержимого.
- В одном запросе несколько файлов → AI анализирует каждый файл отдельно и подтверждает ознакомление с каждым.
- После ознакомления с несколькими файлами пользователь просит саммари → AI может выдать саммари отдельно по каждому файлу.
- Кейс 1: AI получает PDF «Регламент работы AI-сотрудника» → открывает, изучает, подтверждает ознакомление; на новый запрос «о чём этот документ?» готовит саммари / отвечает по содержимому в рамках текущего чата.
- Кейс 2: AI отправлен файл, который нельзя обработать (тип или повреждение) → уведомляет инициатора в духе «Не удалось ознакомиться с документом. Я еще не научился обрабатывать этот тип файла / Файл поврежден» и не обрабатывает содержимое.
