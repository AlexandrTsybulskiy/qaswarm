Пользователь раздела CRM на конкретном лиде видит историю действий: создание, перемещение между стадиями и редактирование. В эту историю не попадают логи, унаследованные от задач и не относящиеся к лиду. Логи по меткам из раздела «для всех сущностей» для лидов сохраняются. Те же логи по лиду пишутся в чат привязанного контакта; при нескольких контактах — во все такие чаты. Текст ошибки в контексте лида: «данного лида», не «данной задачи».

## Testable

- Создать лид → в истории действий этого лида есть запись о создании.
- Переместить лид между стадиями → в истории этого лида есть запись о перемещении.
- Отредактировать лид → в истории этого лида есть запись о редактировании.
- Открыть историю действий лида → логи, которые подтягиваются из задач и не относятся к лиду (их нет в разделе CRM каталога логов), отсутствуют.
- Выполнить на лиде действие с метками (раздел «для всех сущностей» каталога логов) → соответствующие логи остаются в истории лида.
- Выполнить действие по лиду, к которому привязан один контакт → лог по лиду фиксируется в чате этого контакта.
- Выполнить действие по лиду, к которому привязано несколько контактов → лог по лиду фиксируется в чатах всех этих контактов.
- В контексте лида получить ошибку, на скрине которой было «данной задачи» → в тексте «данного лида», не «данной задачи».
