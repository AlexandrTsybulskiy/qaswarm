В карточке контакта (Web) в правой части экрана появляется раздел «Лиды» по аналогии с разделом «Тикеты»: при раскрытии показываются все CRM-лиды, у которых в поле «Контакт» указан открытый контакт; при отсутствии таких лидов — текст «Лиды не найдены»; клик по карточке лида открывает этот лид в новом окне.

## Testable

- Открыть карточку контакта → в правой части экрана есть раздел «Лиды», расположенный по аналогии с разделом «Тикеты».
- Раскрыть раздел «Лиды» у контакта, который указан в поле «Контакт» у одного или нескольких лидов → отображаются все такие лиды, и только они.
- Раскрыть раздел «Лиды» у контакта, который не указан в поле «Контакт» ни у одного лида → отображается текст «Лиды не найдены».
- Нажать на карточку лида в раскрытом разделе «Лиды» → этот лид открывается в новом окне.
