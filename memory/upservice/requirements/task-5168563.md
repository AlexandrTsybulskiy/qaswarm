Глобальный гибридный поиск по системе: полнотекстовый поиск по сущностям и семантический (vector) поиск по сообщениям в чатах сущностей. Пользователь открывает модальное окно поиска (плейсхолдер «Поиск по системе», подсказка горячих клавиш) через Ctrl+K / Command+K или UI; видит только результаты по доступным ему сущностям; при отсутствии совпадений — заглушку «По вашему запросу ничего не найдено.»

## Testable

- В интерфейсе доступен общий поиск по системе → в поле ввода отображается плейсхолдер «Поиск по системе».
- Рядом с полем поиска отображается подсказка о горячей клавише → видна комбинация Ctrl+K (Windows/Linux) или Command+K (macOS) в соответствии с ОС.
- Пользователь нажимает Ctrl+K (Windows/Linux) или Command+K (macOS) в любом разделе системы → открывается одно модальное окно поиска; курсор сразу в поле ввода запроса.
- Окно поиска уже открыто → повторное нажатие той же горячей клавиши не создаёт второе окно.
- В открытом окне поиска нажатие Esc → окно закрывается.
- Пользователь без доступа к сущности выполняет поиск по тексту из её чата/карточки → сообщение и сущность не отображаются в результатах.
- Пользователь с доступом к сущности выполняет поиск по тексту из её чата → результат доступен в выдаче (при совпадении).
- Поиск выполняется по сообщениям разделов: Беседы; Задачи и их чаты; Справочники и их чаты; Тикеты и их чаты; Лиды и их чаты; Контакты и их чаты → для каждого раздела при подходящих данных появляется соответствующий результат.
- В карточке результата отображаются: тип сущности, название сущности, ссылка для перехода в сущность → поля видны; клик по ссылке открывает сущность.
- Для результата по справочнику в карточке отображается ответственный/управляющий → поле присутствует в результате.
- Где у сущности есть id → в результате поиска отображается id сущности.
- Запрос с точным совпадением слов в сообщении/сущности → соответствующий результат в выдаче.
- Запрос с частичным совпадением → соответствующий результат в выдаче.
- Запрос по смыслу (без дословного совпадения), для которого ожидается semantic/vector hit → релевантное сообщение находится в выдаче.
- Несколько результатов → список упорядочен по релевантности; при равной релевантности выше сущности с более новыми обновлениями.
- По запросу нет подходящих сущностей/сообщений → отображается заглушка «По вашему запросу ничего не найдено.»
- Поиск использует гибридный режим (полнотекст по сущностям + семантический поиск по смыслу сообщений) → в выдаче возможны и дословные/частичные, и смысловые совпадения по сообщениям (без требования отдельного переключателя режима в UI, если его нет в АС).
