На личном Web-дашборде сотрудник видит виджет ближайших встреч: события календаря, в которых он участник, с окончанием позже текущего момента и началом в пределах сегодня и завтра, отсортированные по времени начала по возрастанию. Для каждой встречи доступны дата (через контекст дня виджета), время, название, участники и длительность; для онлайн-встречи со ссылкой — кнопка «Подключиться» (открывает ссылку в новой вкладке), без ссылки кнопка скрыта. «Смотреть календарь» / переход к календарю открывает календарь пользователя; при отсутствии встреч на выбранный день — пустое состояние.

## Testable

- Открыть личный дашборд Web под текущим сотрудником → отображается виджет встреч (заголовок «Встречи» / ближайшие встречи)
- У текущего пользователя есть предстоящая встреча на сегодня; открыть вкладку «Сегодня» → встреча отображается в списке виджета
- У текущего пользователя есть предстоящая встреча на завтра; открыть вкладку «Завтра» → встреча отображается в списке виджета
- Пользователь A — участник встречи на сегодня; пользователь B не участник этой встречи; оба открывают вкладку «Сегодня» → встреча есть у A и отсутствует у B
- В виджете отображается встреча → видно время начала
- В виджете отображается встреча → видно время окончания (длительность через интервал начала–окончания)
- В виджете отображается встреча → видно название встречи
- В виджете отображается встреча с участниками → видны участники (аватары / список)
- У встречи есть ссылка для подключения (онлайн) → отображается кнопка «Подключиться»
- Нажать «Подключиться» у встречи со ссылкой → ссылка встречи открывается в новой вкладке
- У встречи нет ссылки для подключения → кнопка «Подключиться» не отображается
- Нажать ссылку перехода к календарю в футере виджета («Смотреть календарь» / «Ко всем встречам») → открывается календарь текущего пользователя
- На вкладке «Сегодня» нет предстоящих встреч текущего пользователя → показывается пустое состояние для сегодня
- На вкладке «Завтра» нет предстоящих встреч текущего пользователя → показывается пустое состояние для завтра
- Встреча текущего пользователя уже закончилась (время окончания ≤ сейчас), день — сегодня → встреча не отображается во вкладке «Сегодня»
- У пользователя несколько предстоящих встреч на выбранный день → в списке они идут по времени начала по возрастанию
