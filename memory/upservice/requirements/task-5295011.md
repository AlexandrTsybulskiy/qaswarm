Менеджер продаж видит автоматический итоговый балл лида, пришедшего через заполнение формы Upservice на сайте: балл = сумма применимых признаков из правил скоринга формы, пересчитывается при изменении полей лида, отображается на карточке лида на Kanban и в карточке лида. Скоринг действует только в workspace **8** и только для лидов с источником «заполнение формы Upservice» (конкретные каналы формы задаются отдельно). Не входит: MQL/порог 50, сортировка и фильтрация по баллу, расшифровка признаков, другие источники лидов, rule builder, другие workspace, мобильные платформы.

## Testable

- Лид в workspace 8, источник — заполнение формы Upservice на сайте → при открытии Kanban и карточки лида отображается рассчитанный итоговый балл
- Лид в workspace, отличном от 8, создан из формы Upservice → итоговый балл скоринга формы не рассчитывается и не отображается на Kanban и в карточке лида
- Лид в workspace 8 с источником, отличным от заполнения формы Upservice (регистрация, мессенджер, звонок, email, чат, ИИ-анализ) → итоговый балл скоринга формы не рассчитывается и не отображается
- Лид из формы: корпоративная почта, осмысленная компания, корректный телефон с мессенджерами, «задача клиента» — релевантная Upservice потребность, 6–20 пользователей → итоговый балл **105** (40+5+5+30+25); на Kanban и в карточке лида отображается 105
- Лид из формы: временная почта, фиктивное имя, фиктивный телефон, «задача клиента» — потенциально НЕцелевая потребность, 1 пользователь → итоговый балл **−25** (40−30−10−15+0−10); на Kanban и в карточке лида отображается −25
- Лид из формы: корпоративная почта, осмысленная компания, 2–5 пользователей, «задача клиента» — не является потенциальным покупателем → итоговый балл **10** (40+5+5−50+10); на Kanban и в карточке лида отображается 10
- Лид создан из заполнения формы Upservice → к сумме применяется **+40** за факт заполнения формы
- У лида из формы корпоративная почта → к сумме **+5**
- У лида из формы временная/фейковая почта → к сумме **−30**
- У лида из формы осмысленное название компании → к сумме **+5**
- У лида из формы фиктивное название компании → к сумме **−10**
- У лида из формы фиктивное имя → к сумме **−10**
- У лида из формы фиктивный телефон → к сумме **−15**
- У лида из формы отсутствует номер телефона → к сумме **−10**
- У лида из формы указан ненфиктивный номер телефона, на нём нет мессенджеров (tg, wa, max, viber) → к сумме **−20**
- У лида из формы указан фиктивный номер или номер отсутствует → штраф «нет мессенджеров» (**−20**) не применяется
- Ответ «Для каких задач ищите систему?» — релевантная Upservice потребность → **+30**; потенциально релевантная → **+20**; потенциально НЕцелевая → **0**; не является потенциальным покупателем → **−50**
- Ответ «Сколько человек будут работать в системе?» — 1 человек → **−10**; 2–5 → **+10**; 6–20 → **+25**; 21–50 → **+30**; 51+ → **+40**
- У лида из формы в workspace 8 изменены поля, влияющие на признаки скоринга (в т.ч. поля формы) → итоговый балл пересчитывается; на Kanban и в карточке лида отображается новое значение
- Лид из формы в workspace 8 с рассчитанным баллом → на карточке лида на Kanban виден итоговый балл
- Лид из формы в workspace 8 с рассчитанным баллом → в карточке лида виден итоговый балл (тот же итог, что на Kanban)
- Лид с рассчитанным баллом → в карточке лида нет расшифровки (списка сработавших признаков)
- Kanban с лидами, у которых есть балл → нет сортировки и фильтрации по баллу
- Лид с баллом на мобильном клиенте (Android/iOS) → балл скоринга формы не отображается
- Лид с баллом → нет отдельного индикатора MQL и автоматической отметки по порогу 50 баллов (это другие задачи)
