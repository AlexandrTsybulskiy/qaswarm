На страницах **«Клиенты → Контакты и чаты»** и **«CRM»** добавляется фильтр **«Контрагент»** с мультивыбором. При выборе одного или нескольких контрагентов список контактов и канбан лидов показывают только записи, связанные **хотя бы с одним** из выбранных контрагентов; записи без контрагента скрываются. Фильтр сочетается с другими активными фильтрами и поиском на той же странице. При пустом выборе в фильтре «Контрагент» поведение страниц остаётся как до применения фильтра.

## Testable

- Пользователь открывает **«Клиенты → Контакты и чаты»** → в панели фильтров доступен фильтр **«Контрагент»**
- Пользователь открывает страницу **«CRM»** → в панели фильтров доступен фильтр **«Контрагент»**
- Пользователь открывает фильтр **«Контрагент»** на «Контакты и чаты» или «CRM» → можно выбрать **одного** контрагента
- Пользователь открывает фильтр **«Контрагент»** → можно выбрать **нескольких** контрагентов одновременно
- В воркспейсе есть контрагент «ООО Ромашка» и три контакта: два связаны с «ООО Ромашка», один без контрагента; пользователь на «Контакты и чаты» выбирает в фильтре «Контрагент» **«ООО Ромашка»** → в списке остаются **два** контакта, связанных с «ООО Ромашка»; контакт **без контрагента не отображается**
- На канбане CRM есть лиды, связанные с «ООО Ромашка», «ИП Иванов» и без контрагента; пользователь в фильтре «Контрагент» выбирает **«ООО Ромашка»** и **«ИП Иванов»** → на канбане видны лиды, связанные с «ООО Ромашка» **или** «ИП Иванов»; лиды **без контрагента скрыты**
- На «Контакты и чаты» активен фильтр «Контрагент» с выбранным «ООО Ромашка»; пользователь **очищает** выбор в фильтре «Контрагент» → отображаются **все** контакты, доступные пользователю на странице, **как до** применения фильтра
- На «CRM» активен фильтр «Контрагент» с одним или несколькими выбранными контрагентами; пользователь **очищает** выбор в фильтре «Контрагент» → на канбане отображаются **все** лиды, доступные пользователю, **как до** применения фильтра
- На «Контакты и чаты» одновременно активны фильтр «Контрагент», **другие** фильтры страницы и **поиск** → в списке остаются только контакты, удовлетворяющие **всем** активным условиям, включая связь хотя бы с одним выбранным контрагентом
- На «CRM» одновременно активны фильтр «Контрагент», **другие** фильтры панели и **поиск** → на канбане остаются только лиды, удовлетворяющие **всем** активным условиям, включая связь хотя бы с одним выбранным контрагентом
- Контакт связан **с несколькими** контрагентами; в фильтре «Контрагент» выбран **один** из них → контакт **отображается** в списке «Контакты и чаты»
- Лид связан **с несколькими** контрагентами; в фильтре «Контрагент» выбран **один** из них → лид **отображается** на канбане CRM
