В разделе «Правила автоматизации» пользователь настраивает автоматическую смену воронки и стадии лида после финализации статуса доставки отложенного сообщения контакту. Триггер «Отправка отложенного сообщения контакту» срабатывает при финальном статусе «Отправлено» или «Не отправлено». Для веток «Доставлено» и «Не доставлено» задаются отдельные правила с целевой воронкой и стадией.

## Testable

- Открыть «Правила автоматизации» → в типе сущности доступен «Отложенное сообщение»
- Создать правило с типом «Отложенное сообщение» → в триггерах доступен «Отправка отложенного сообщения контакту»
- Отложенному сообщению присвоен финальный статус «Отправлено» → триггер «Отправка отложенного сообщения контакту» срабатывает
- Отложенному сообщению присвоен финальный статус «Не отправлено» → триггер «Отправка отложенного сообщения контакту» срабатывает
- В правиле заданы условия «статус отправки отложенного», «воронка лида на момент отправки», «стадия лида на момент отправки» → все три условия проверяются одновременно (логика «И»)
- В действии правила выбрано «Сменить воронку и статус лида» → доступны поля «Воронка» и «Статус»
- Настроить правило с условием «Доставлено» и целевой воронкой/стадией → правило сохраняется с одной веткой «Доставлено»
- Настроить отдельное правило с условием «Не доставлено» и целевой воронкой/стадией → правило сохраняется с одной веткой «Не доставлено»
- Отложенное сообщение отправлено в контексте контакта, у контакта есть связанный лид на стадии из условия правила, доставка «Доставлено» → лид переводится на целевую воронку и стадию из действия
- Отложенное сообщение отправлено в контексте контакта, у контакта есть связанный лид на стадии из условия правила, доставка «Не доставлено» → лид переводится на целевую воронку и стадию из действия правила «Не доставлено»
- Целевая воронка и стадия совпадают с текущими у лида → смена пропускается без ошибки пользователю
- В списке правил есть активное и неактивное с триггером «Отправка отложенного сообщения контакту» → при срабатывании применяется только активное
- Несколько активных правил с одним триггером в разном порядке списка → при срабатывании правила применяются в порядке списка
- Автоматическая смена воронки и стадии лида → результат совпадает с ручной сменой в карточке лида CRM
- Автоматическая смена воронки и стадии лида → результат совпадает с ручной сменой на kanban CRM
- Отложенное сообщение отправлено до активации правила → после активации правила смена для этого сообщения не выполняется (без backfill)
- Изменить параметры уже активного правила → смена применяется только к новым срабатываниям после изменения
- Пользователь без прав управления правилами автоматизации → раздел «Правила автоматизации» недоступен или настройка запрещена
- Пользователь с правами управления правилами автоматизации → может создавать и редактировать правила с триггером «Отправка отложенного сообщения контакту»
- Пример из задачи: правило «Отправлено», воронка «Продажи», стадия «Квалификация», действие «Продажи» / «Follow-up доставлен», лид на «Квалификация», доставка «Доставлено» → лид на «Продажи» / «Follow-up доставлен»
