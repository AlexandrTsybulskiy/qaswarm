Пользователь поручает **ИИ-сотруднику** создать **пользовательский отчёт** прямо в диалоге чата (контакт, задача и другие чаты, где доступен ИИ-сотрудник). За один запрос создаётся не более одного отчёта. После успешного построения ИИ-сотрудник отправляет в **тот же чат** сообщение с **названием отчёта** и действием **«Открыть отчёт»**; по действию открывается страница этого отчёта. Отчёт появляется во вкладке **«Пользовательские отчёты»** раздела **«Отчёты»** workspace компании и доступен пользователю, сделавшему запрос. Если параметры (метрики, период, срез, тип визуализации и т.п.) нельзя определить однозначно — ИИ-сотрудник задаёт уточняющие вопросы и не создаёт отчёт до ответа. Отчёт содержит только данные, которые запрашивающий пользователь имеет право видеть — по тем же правилам, что при **ручном** создании пользовательского отчёта. При ошибке построения ИИ-сотрудник сообщает об этом в чате; отчёт в список не добавляется. Ручное создание и просмотр системных и пользовательских отчётов в интерфейсе остаётся без изменений. Для построения отчётов ИИ-сотруднику выдаются права в **Superset** через админку.

## Testable

- Пользователь в чате контакта с ИИ-сотрудником; запрос с однозначными параметрами («Сделай отчёт по лидам за последний месяц с разбивкой по этапам воронки») → создан **один** пользовательский отчёт; в том же чате появляется сообщение с **названием отчёта** и действием **«Открыть отчёт»**
- Пользователь нажимает **«Открыть отчёт»** в сообщении ИИ-сотрудника в чате → открывается **страница** созданного отчёта (тот же отчёт, что создан по запросу)
- После успешного создания отчёта из чата → отчёт отображается во вкладке **«Пользовательские отчёты»** раздела **«Отчёты»** workspace компании и **доступен** пользователю, сделавшему запрос
- Пользователь в **чате задачи** с ИИ-сотрудником; запрос с однозначными параметрами отчёта → создан один пользовательский отчёт; в чате — сообщение с названием и **«Открыть отчёт»**; отчёт доступен во вкладке **«Пользовательские отчёты»**
- За **один** запрос пользователя в диалоге с ИИ-сотрудником → обрабатывается **не более одного** отчёта (второй отчёт из того же сообщения не создаётся)
- Пользователь пишет «Сделай отчёт по продажам» без периода, метрик и среза → ИИ-сотрудник **задаёт уточняющие вопросы** (например, период, метрики, срез) и **не создаёт** отчёт
- Пока параметры отчёта не уточнены пользователем → отчёт **не появляется** во вкладке «Пользовательские отчёты» и сообщение с **«Открыть отчёт»** **не отправляется**
- После ответа пользователя на уточняющие вопросы по ранее неоднозначному запросу → ИИ-сотрудник **создаёт** пользовательский отчёт по уточнённым параметрам
- При **ошибке** построения отчёта → ИИ-сотрудник **сообщает об ошибке** в том же чате; отчёт **не добавляется** во вкладку «Пользовательские отчёты»
- Отчёт, созданный по запросу пользователя → содержит **только** данные, которые этот пользователь имеет право видеть в Upservice (**те же правила**, что при ручном создании пользовательского отчёта в интерфейсе)
- Пользователь без доступа к части данных, относящихся к запрошенной аналитике → созданный для него отчёт **не раскрывает** недоступные данные (поведение как при ручном пользовательском отчёте)
- **Ручное** создание пользовательского отчёта в разделе «Отчёты» интерфейса → работает **без изменений** относительно поведения до Story
- **Ручной** просмотр **системных** отчётов в интерфейсе → работает **без изменений**
- **Ручной** просмотр **пользовательских** отчётов в интерфейсе → работает **без изменений**
- ИИ-сотрудник **не имеет** прав построения отчёта в Superset (не настроен в админке) → запрос на создание отчёта из чата завершается **ошибкой**; ИИ-сотрудник сообщает об этом в чате; отчёт в «Пользовательские отчёты» **не попадает**
