На карточке лида в CRM показывается специальная иконка неотвеченного вызова (в макете — индикатор с иконкой `phone-call-01` рядом с контактной строкой / индикатором сообщений), чтобы пользователь видел, кому нужно перезвонить. Иконка видна и на карточке в **CRM Kanban**, и в карточке лида на **detail**. После **первого** исходящего сообщения со стороны Upservice иконка исчезает — в том числе когда у лида было несколько неотвеченных вызовов. Существующие элементы CRM (колонки Kanban по стадиям, плашка стадии на карточке, split-view карточки лида, плашка стадии в заголовке) сохраняются без регрессии.

## Testable

- У лида есть один неотвеченный вызов; пользователь открывает CRM Kanban → на карточке лида отображается специальная иконка неотвеченного вызова
- У лида есть один неотвеченный вызов; пользователь открывает карточку лида в detail → в карточке лида отображается специальная иконка неотвеченного вызова
- У лида есть один неотвеченный вызов и специальная иконка отображается; пользователь отправляет первое сообщение со стороны Upservice → специальная иконка у лида исчезает
- У лида есть несколько неотвеченных вызовов и специальная иконка отображается; пользователь отправляет первое сообщение со стороны Upservice → специальная иконка у лида исчезает
- Пользователь открывает CRM Kanban после изменения → колонки Kanban по стадиям отображаются как до изменения
- Пользователь открывает CRM Kanban → на карточках лидов отображается плашка стадии
- Пользователь открывает карточку лида → доступен split-view карточки лида
- Пользователь открывает карточку лида → в заголовке карточки лида отображается плашка стадии

## Gaps

- В `entities/` нет карточек лида / CRM / звонков → `entities: none`. Не выдумывать slug.
- В `catalog/api.md` нет публичных ресурсов CRM leads / missed calls / call indicators. Не выдумывать эндпоинты.
- Точное определение «неотвеченный вызов» (пропущенный входящий, непринятый исходящий, длительность, источник канала) в AC не зафиксировано.
- Что считается «сообщением со стороны Upservice» (канал чата, SMS, шаблон, внутренний комментатор) и что такое «первое» (после появления индикатора / за всё время) — не детализировано.
- Поведение при ответе на звонок без сообщения, при исходящем звонке сотрудника, при повторном неотвеченном вызове после сброса иконки — не описано.
- Совместное отображение с индикатором непрочитанных сообщений (`message-notify-circle` в том же блоке макета) и приоритет/порядок иконок в AC не заданы; в Figma оба индикатора могут быть рядом.
- Android/iOS в Design = «-»; scope — Web по приложенному Figma.
- Pixel-perfect цвет/размер иконки сверх факта «специальная иконка» в AC не названы; ориентир макета — `phone-call-01` в `CRM_massege_indicator` на карточке Lead в Kanban CRM (node `129430:155592`). Отдельный detail-фрейм в открытом узле не разобран — сверить при verify.
- Поиск по коду frontend/backend в этом проходе не выполнялся (sync внешних репо заблокирован) → секция Implementation hints отсутствует.
