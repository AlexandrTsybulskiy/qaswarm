После пересчёта итогового балла скоринга лида (registered/form scoring) система проверяет правило автоперехода: если лид в воронке с точным названием «Воронка квалификации», на статусе с точным названием «Лид», итоговый балл ≥ 50 и нет запрета MQL — статус воронки автоматически меняется на «MQL» так же, как при ручном перемещении на Kanban или в карточке. Ниже порога, при запрете MQL, уже на «MQL» / дальше, в других воронках или статусах, а также при отсутствии воронки/статусов в workspace — автоперехода нет (без ошибки UI). Падение балла после «MQL» не откатывает статус автоматически. При автосмене в истории действий лида появляется запись об автоматическом изменении.

## Testable

- Лид в воронке «Воронка квалификации» на статусе «Лид», итоговый балл скоринга после пересчёта ≥ 50 (например 52), запрета MQL нет → статус воронки становится «MQL»; лид в колонке «MQL» на Kanban
- Лид в воронке «Воронка квалификации» на статусе «Лид», итоговый балл скоринга после пересчёта ровно 50, запрета MQL нет → статус воронки автоматически становится «MQL»
- Автопереход на «MQL» сработал → в истории действий лида есть запись об автоматическом изменении статуса воронки
- Лид в воронке «Воронка квалификации» на статусе «Лид», итоговый балл ≥ 50, действует запрет MQL («Не является потенциальным покупателем») → статус воронки автоматически остаётся «Лид»
- У лида с запретом MQL менеджер с правом смены статуса воронки вручную переводит лид на «MQL» → статус меняется; в истории действий — запись о ручной смене статуса (не автоматическая)
- Лид в воронке «Воронка квалификации» на статусе «Лид», итоговый балл после пересчёта < 50 (например 42), запрета MQL нет → статус воронки автоматически остаётся «Лид»
- Лид с баллом < 50 на статусе «Лид»; менеджер с правом смены статуса вручную переводит на «MQL» → статус меняется
- Лид уже на статусе «MQL» в «Воронка квалификации»; пересчёт скоринга (в т.ч. балл ниже 50) → статус воронки автоматически не меняется
- Лид на статусе дальше «MQL» в «Воронка квалификации»; пересчёт скоринга с баллом ≥ 50 → статус воронки автоматически не меняется
- Лид уже на «MQL»; итоговый балл после пересчёта падает ниже 50 (например 38) → статус воронки автоматически остаётся «MQL» (без отката)
- Лид в другой воронке (не «Воронка квалификации») на статусе «Лид»; пересчёт с баллом ≥ 50 без запрета MQL → статус воронки этим правилом не меняется
- Лид в «Воронка квалификации» на статусе, отличном от «Лид» и не требующем автоперехода на «MQL»; пересчёт с баллом ≥ 50 → статус этим правилом не меняется
- В workspace нет воронки «Воронка квалификации» или статусов «Лид» / «MQL»; происходит пересчёт скоринга лида → лиды не меняются; ошибка пользователю не показывается
