Пользователь из карточки **тикета** может создать **лида**, чтобы продолжить работу с контактом после разового обращения. В меню добавления сущностей тикета появляется пункт **Лид**; по клику открывается дровер создания лида с дополнительным обязательным полем **Воронка** (список воронок воркспейса). При открытии того же дровера из раздела **CRM** поле **Воронка** не показывается; дровер редактирования лида не меняется. Поля **Название**, **Описание**, **Контакт**, **Ответственный** и **Метки** предзаполняются из тикета.

## Testable

- Открыть тикет в статусе «В работе» или «Ожидает ответа» → в меню кнопки «Добавить» виден пункт «Лид»
- Нажать «Лид» в меню «Добавить» тикета → открывается дровер создания лида
- Открыть дровер создания лида из тикета → поле «Воронка» отображается
- Открыть дровер создания лида из раздела CRM (кнопка «Добавить» в шапке CRM) → поле «Воронка» не отображается
- Создать лид из тикета с заполненными данными → поле «Название» предзаполнено из тикета
- Создать лид из тикета с заполненными данными → поле «Описание» предзаполнено из тикета
- Создать лид из тикета с привязанным контактом → поле «Контакт» предзаполнено контактом тикета
- Создать лид из тикета с назначенным ответственным → поле «Ответственный» предзаполнено ответственным тикета
- Создать лид из тикета с метками → поле «Метки» предзаполнено метками тикета
- В дровере создания лида из тикета оставить поле «Воронка» пустым и нажать «Создать» → создание не завершается; отображается ошибка обязательного поля
- Открыть выпадающий список поля «Воронка» в дровере из тикета → в списке отображаются воронки текущего воркспейса
- Заполнить обязательные поля в дровере из тикета и нажать «Создать» → лид создан; открывается карточка созданного лида

### Частично / расходится с задачей

- Поле «Воронка» показывается и из тикета, и из CRM — `MainForm.renderPipeline()` без условия контекста; из CRM `Crm.tsx` открывает тот же дровер с `data: {}`, pipeline подставляется из `getCrmSelectedPipeline`, но поле остаётся видимым (в тикете — должно быть видно, из CRM — скрыто)
- «Название»: в коде в `title` передаётся ФИО контакта (`getFullName(contactDetails)`), а не заголовок тикета (`ticket.title`)
- Пункт «Лид» доступен только когда тикет «В работе» или «Ожидает ответа»; в критериях статусы не ограничены
- В форме также обязателен «Статус лида» (`FormPipelineStatusSelect`); в критериях приёмки не описан
