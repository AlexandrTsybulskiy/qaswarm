При создании массовой рассылки пользователь может сгенерировать пул уникальных вариантов текста сообщения через LLM (логика Spintax): кнопка появляется после ≥30 символов в поле «Сообщение», AI отдаёт 10 альтернатив с сохранением смысла, без изменения ссылок, переменных/шаблонов, контактов и промокодов; перед отправкой показываются первые 3 варианта с раскрытием «Показать все»; при отправке каждому получателю выбирается один вариант (один вариант может достаться нескольким); повторная генерация до старта рассылки без лимита.

## Testable

- При создании массовой рассылки пользователь запускает генерацию пула уникальных сообщений → система создаёт пул вариантов по логике Spintax / LLM-генерации из исходного текста поля «Сообщение»
- В поле «Сообщение» введено меньше 30 символов → кнопка «Генерировать уникальные сообщения» не отображается
- В поле «Сообщение» введено минимум 30 символов → кнопка «Генерировать уникальные сообщения» отображается
- Пользователь нажимает «Генерировать уникальные сообщения» → система передаёт исходный текст сообщения в LLM для генерации вариантов
- Генерация завершается успешно → AI создаёт ровно 10 альтернативных вариантов сообщения с сохранением исходного смысла и цели коммуникации (синонимы, перестановка предложений, изменение структуры и иные языковые приёмы)
- В исходном тексте есть ссылки → во всех сгенерированных вариантах ссылки сохранены без изменения
- В исходном тексте есть переменные и шаблоны подстановки → во всех сгенерированных вариантах переменные и шаблоны сохранены без изменения
- В исходном тексте есть контактные данные → во всех сгенерированных вариантах контактные данные сохранены без изменения
- В исходном тексте есть промокоды → во всех сгенерированных вариантах промокоды сохранены без изменения
- Перед отправкой рассылки пользователь открывает просмотр сгенерированных вариантов → система показывает первые 3 варианта
- В режиме просмотра пользователь нажимает «Показать все» → отображаются все сгенерированные варианты пула
- Рассылка отправляется нескольким получателям при наличии сгенерированного пула → каждому получателю выбирается один вариант из пула
- Число получателей больше числа уникальных вариантов в пуле → один и тот же вариант может быть использован для нескольких получателей
- До начала рассылки пользователь повторно нажимает генерацию (в том числе многократно) → система выполняет новую генерацию без ограничения числа попыток
