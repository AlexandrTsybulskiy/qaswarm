На карточке контрагента (**«Клиенты → Контрагенты»**) добавляется таб **«Лиды»** со списком лидов, связанных с этим контрагентом, и переходом в карточку лида по клику — как при открытии лида из CRM. В левой панели карточки контрагента появляется поле **«Заметки»**: пользователь вводит и сохраняет текст заметки для конкретного контрагента; при повторном открытии карточки сохранённый текст отображается. Табы **«История»**, **«Контакты»**, **«Сделки»** и **«Реквизиты»** продолжают работать как до изменений.

## Testable

- Пользователь открывает карточку контрагента через **«Клиенты → Контрагенты»** → на карточке доступен таб **«Лиды»**
- У контрагента «ООО Ромашка» в CRM есть **два** лида, связанных с этой компанией, и в воркспейсе есть **один** лид другого контрагента; пользователь открывает карточку «ООО Ромашка» и переходит на таб **«Лиды»** → в списке отображаются **два** лида «ООО Ромашка»; лид другого контрагента **не показывается**
- На табе **«Лиды»** контрагента отображается лид «Поставка оборудования»; пользователь **нажимает** на этот лид в списке → открывается **карточка лида** «Поставка оборудования» (тот же экран, что при переходе к лиду из **CRM**)
- Пользователь открывает карточку контрагента → в **левой панели** доступно поле **«Заметки»**
- У контрагента «ИП Иванов» заметка **не заполнена**; пользователь в поле **«Заметки»** вводит «Перезвонить в пятницу» и **сохраняет** → при повторном открытии карточки «ИП Иванов» в поле «Заметки» отображается **«Перезвонить в пятницу»**
- Пользователь открывает карточку контрагента → табы **«История»**, **«Контакты»**, **«Сделки»** и **«Реквизиты»** **доступны** и открываются без регрессии относительно текущего поведения
