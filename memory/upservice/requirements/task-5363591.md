На канбане воронки CRM в существующем меню сортировки появляется опция **«По приоритетам»**. По умолчанию остаётся **«По дате создания»**; остальные уже существующие опции сортировки сохраняются. При выборе **«По приоритетам»** карточки лидов упорядочиваются **внутри каждой колонки стадии** по уровням сигнала ответа (1 выше 2, 2 выше 3, 3 выше 4; при нескольких сигналах берётся наивысший уровень). Фильтры, поиск и **«Только мои»** сначала сужают набор; сортировка упорядочивает уже отфильтрованный набор.

Уровни: **1** — пропущенный входящий звонок; **2** — входящее сообщение с просьбой о конкретном следующем шаге (договор, КП, демо, счёт, условия подключения или назначить созвон); **3** — входящее без такого шага с формулировками «Нам интересно», «Расскажите подробнее», «Хотим узнать больше»; **4** — нет сигналов 1–3, порядок по убыванию числового балла скоринга (нет балла = 0). Внутри уровней 1–3 выше лид с более ранним сигналом этого уровня (скоринг порядок не меняет). Внутри уровня 4 при равном балле выше лид, созданный раньше. Сообщение «Спасибо, посмотрим» не даёт уровни 2 и 3.
