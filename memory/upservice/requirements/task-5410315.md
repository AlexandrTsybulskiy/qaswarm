Как сотрудник, ведущий лиды на канбане CRM, после успешного создания или редактирования конкретного лида сразу видит актуальную карточку, количества и суммы без перезагрузки страницы. Live-update в других открытых сессиях той же воронки получают только **автор** и **ответственный** лида (новый ответственный включается после сохранения; бывший — только если он всё ещё автор). Участники и сотрудники выше в иерархии сами по себе live-update не получают. Карточка на канбане обновляется при изменении названия, контакта, ответственного, суммы или валюты (метки и прочие поля вне этого списка). Смена воронки/статуса обновляет карточку и количества/суммы исходного и нового статуса; позиция в колонке — по активной сортировке и фильтрам сессии. При одновременном редактировании на карточке побеждает последнее успешное сохранение. Изменение структуры воронки в настройках на открытых канбанах видно только после reload (сессия из настроек — при возврате на доску); это событие не сужается кругом автора/ответственного/участников лида.

## Testable

- Сотрудник на канбане CRM успешно создаёт лид через **«Добавить»** → без reload обновляются карточка этого лида, количество лидов по статусам и по воронке и сумма поля **«Сумма»** по статусам и по воронке
- Сотрудник успешно создаёт лид из **тикета** → без reload на канбане затронутой воронки обновляются карточка лида, количества и суммы по статусам и по воронке
- Сотрудник успешно создаёт лид из **сообщения** → без reload на канбане затронутой воронки обновляются карточка лида, количества и суммы по статусам и по воронке
- Лид успешно **автосоздаётся** → без reload на канбане затронутой воронки обновляются карточка лида, количества и суммы по статусам и по воронке
- Сотрудник успешно редактирует лид в **деталях** → без reload на канбане обновляются карточка этого лида, количества и суммы по статусам и по воронке
- Сотрудник успешно меняет статус лида из **списка статусов** → без reload на канбане обновляются карточка лида, количества и суммы по статусам и по воронке
- Сотрудник успешно меняет статус лида **перетаскиванием** → без reload на канбане обновляются карточка лида, количества и суммы по статусам и по воронке
- После успешного сохранения лида на канбане → **количество** статуса отображается в шапке колонки
- После успешного сохранения лида на канбане → **сумма** статуса отображается в шапке колонки рядом со счётчиком
- После успешного сохранения лида на канбане → **количество** воронки отображается у общего счётчика лидов
- После успешного сохранения лида на канбане → **сумма** воронки отображается рядом с общим количеством лидов
- У Анны (автор) и Марии (новый ответственный) открыт канбан той же воронки; Анна успешно меняет ответственного с Бориса на Марию → без reload канбаны Анны и Марии показывают Марию ответственным и пересчитанные количества/суммы
- У Бориса (бывший ответственный, после сохранения простой участник), Веры (участник) и Кирилла (выше в иерархии, не автор/ответственный/участник) открыт канбан той же воронки; Анна успешно меняет ответственного с Бориса на Марию → канбаны Бориса, Веры и Кирилла это изменение лида **не получают** без ручной перезагрузки
- У сессии, которая получает live-update, на карточке лида меняют **название** (успешное сохранение другой сессией) → без reload на карточке отображается новое название
- У сессии, которая получает live-update, на карточке лида меняют **контакт** (успешное сохранение другой сессией) → без reload на карточке отображается новый контакт
- У сессии, которая получает live-update, на карточке лида меняют **ответственного** (успешное сохранение другой сессией) → без reload на карточке отображается новый ответственный
- У сессии, которая получает live-update, на карточке лида меняют **сумму** (успешное сохранение другой сессией) → без reload на карточке отображается новая сумма
- У сессии, которая получает live-update, на карточке лида меняют **валюту** (успешное сохранение другой сессией) → без reload на карточке отображается новая валюта
- У сессии, которая получает live-update, на лиде меняют только **метки** (успешное сохранение другой сессией) → без reload карточка на канбане **не** обновляется по меткам (метки вне списка live-update полей)
- Статус лида не менялся; успешно изменены сумма или валюта → карточка остаётся в той же колонке
- Статус лида не менялся; успешно изменены сумма или валюта → количество лидов по статусу и по воронке **не** меняется
- Статус лида не менялся; успешно изменены сумма или валюта → сумма статуса и воронки **пересчитывается**
- Лид успешно переносят в другой статус **той же** воронки → без reload карточка переезжает в колонку нового статуса; количества и суммы исходного и нового статуса обновляются
- У Анны (автор) открыт канбан «Входящие», у Марии (ответственный) — канбан «Продажи»; Анна успешно переносит лид из «Входящие» / «Новый» в «Продажи» / «В работе» → на канбане «Входящие» у Анны карточка исчезает, количества и суммы статуса «Новый» и воронки «Входящие» пересчитаны без этого лида
- У Анны (автор) открыт канбан «Входящие», у Марии (ответственный) — канбан «Продажи»; Анна успешно переносит лид из «Входящие» / «Новый» в «Продажи» / «В работе» → на канбане «Продажи» у Марии карточка появляется в «В работе», количества и суммы статуса «В работе» и воронки «Продажи» пересчитаны
- У Веры (участник, не автор и не ответственный) открыт канбан «Входящие»; Анна успешно переносит лид из «Входящие» в другую воронку → у Веры канбан **автоматически не обновляется**
- У Веры и Марии (обе получают live-update) открыт канбан «Продажи» с разной активной сортировкой сессии; лид успешно переносят в статус «В работе» той же воронки → в обеих сессиях без reload карточка в колонке «В работе»; место карточки у каждой соответствует **активной сортировке её сессии**
- Один лид одновременно открыт на редактирование у Анны и Бориса (обе сессии получают live-update); Анна успешно сохраняет название «Лид А», затем Борис успешно сохраняет название «Лид Б» → на карточке у сессий с live-update без reload отображается **«Лид Б»**
- Сотрудник успешно сохраняет изменения **структуры воронки** в настройках (состав, имена, цвета, порядок колонок) → открытые канбаны этой воронки показывают новую структуру и лиды под неё **только после reload**
- Сотрудник успешно сохраняет изменения структуры воронки в настройках и **возвращается на доску** в той же сессии → на канбане видна новая структура без отдельного требования к кругу автора/ответственного лида
