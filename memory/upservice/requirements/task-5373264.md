Оунер воркспейса подключает **Яндекс Диск** в **«Настройки → Интеграции → Интеграции воркспейса»**: карточка с подключением, отображением подключённого аккаунта и отключением с подтверждением. Подключать и отключать может только оунер; у сотрудника без роли оунера блок «Интеграции воркспейса» недоступен для подключения (как сейчас для Google Диска). Одновременно в воркспейсе подключён только один диск воркспейса — **Google Диск** или **Яндекс Диск**: если ни один не подключён, оунер может подключить любой; если один подключён, второй подключить нельзя, пока первый не отключён. Попытка подключить второй диск **не** отключает первый автоматически. После подтверждённого отключения Яндекс Диска интеграция снята; воркспейс без диска воркспейса ведёт себя как сейчас в этом состоянии. При подключённом Яндекс Диске доступна загрузка файлов в него.

## Testable

- Оунер воркспейса открывает «Настройки → Интеграции → Интеграции воркспейса» → в блоке есть карточка Яндекс Диска
- Оунер воркспейса; диск воркспейса не подключён; на карточке Яндекс Диска нажимает подключить и завершает OAuth → Яндекс Диск подключён
- Оунер воркспейса; Яндекс Диск подключён → на карточке Яндекс Диска показан подключённый аккаунт
- Оунер воркспейса; Яндекс Диск подключён; на карточке запускает отключение → показано подтверждение отключения
- Оунер воркспейса; Яндекс Диск подключён; подтверждает отключение → интеграция Яндекс Диска снята
- Сотрудник без роли оунера открывает «Настройки → Интеграции» → блок «Интеграции воркспейса» недоступен для подключения Яндекс Диска
- Оунер воркспейса; ни Google Диск, ни Яндекс Диск не подключены → доступно подключение Google Диска
- Оунер воркспейса; ни Google Диск, ни Яндекс Диск не подключены → доступно подключение Яндекс Диска
- Оунер воркспейса; Google Диск уже подключён → подключить Яндекс Диск нельзя
- Оунер воркспейса; Яндекс Диск уже подключён → подключить Google Диск нельзя
- Оунер воркспейса; Google Диск уже подключён; пытается подключить Яндекс Диск → Google Диск остаётся подключённым (первый диск автоматически не отключается)
- Оунер воркспейса; Яндекс Диск уже подключён; пытается подключить Google Диск → Яндекс Диск остаётся подключённым (первый диск автоматически не отключается)
- Оунер воркспейса; после подтверждённого отключения Яндекс Диска воркспейс без диска воркспейса → поведение как сейчас в состоянии без подключённого диска воркспейса
- Оунер воркспейса; Яндекс Диск подключён; загружает файл через UI вложения/загрузки → файл загружается в подключённый Яндекс Диск
