На карточке лида поле «Контакт» остаётся обязательным, но принимает более одной сущности. При открытии лида открывается чат с первым контактом в списке прикреплённых (всегда один и тот же контакт). Вверху чата справа на карточке показываются аватарки всех прикреплённых контактов; переключение между ними через выпадающий список подменяет чат и контактную информацию на выбранный контакт. Иконка канала на аватаре контакта(-ов) в чате лида убрана.

## Testable

- Создать или сохранить лид без контакта → сохранение не проходит; поле «Контакт» остаётся обязательным.
- В поле «Контакт» на карточке лида добавить более одной сущности контакта → лид сохраняется с несколькими прикреплёнными контактами.
- Открыть лид с несколькими прикреплёнными контактами → открывается чат с первым контактом в списке; при повторных открытиях того же лида снова открывается чат с тем же первым контактом.
- Открыть лид с несколькими контактами → в правой части карточки вверху чата видны аватарки всех прикреплённых контактов; доступен выпадающий список для переключения между контактами лида.
- В чате лида через выпадающий список переключить активный контакт на другой → чат подменяется на чат с новым контактом; контактная информация отображается по новому контакту.
- Открыть чат лида с одним или несколькими контактами → на аватаре контакта(-ов) в чате лида нет иконки канала.
