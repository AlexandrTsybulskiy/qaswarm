Пользователь может создать копию лида из меню карточки на канбане и из меню развёрнутой карточки: открывается дровер создания лида с предзаполненными полями исходного лида, включая текущие воронку и статус. Копирование доступно на любом статусе; воронку и статус копии можно сменить (при смене воронки список статусов обновляется, по умолчанию — начальный статус новой воронки). Связи исходного лида копируются по той же логике, что у задач; дополнительные связи не создаются.

## Testable

- Открыть меню карточки лида в режиме канбан → в меню есть пункт «Создать копию лида»
- Открыть меню развёрнутой карточки лида → в меню есть пункт «Создать копию лида»
- Лид в начальном статусе воронки; выбрать «Создать копию лида» → копирование доступно
- Лид в промежуточном статусе воронки; выбрать «Создать копию лида» → копирование доступно
- Лид в конечном статусе воронки; выбрать «Создать копию лида» → копирование доступно
- Нажать «Создать копию лида» → открывается дровер создания лида
- В открытом дровере копии проверить поля → заполненные значения полей исходного лида прокинуты; отображаются поля «Воронка» и «Статус» с предзаполнением текущей воронки и текущего статуса исходного лида
- В дровере сменить воронку → в поле «Статус» подтягивается список статусов новой воронки; по умолчанию выбран начальный статус этой воронки
- Выбрать другую воронку и статус в дровере и сохранить копию → новый лид создан в выбранной воронке в выбранном статусе
- Сохранить копию без смены воронки и статуса → новый лид создан в текущей воронке в текущем статусе исходного лида
- У исходного лида есть связи; создать копию → на новом лиде сохранены те же связи, что у исходного (как при копировании задачи)
- Создать копию лида → дополнительных связей сверх логики копирования задач не появляется
