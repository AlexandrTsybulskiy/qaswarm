На личном Web-дашборде появляется виджет **«План на текущую неделю»**: единый обзор активных работ текущего пользователя с заполненным сроком «Выполнить по» (или сроком действия записи справочника), попадающим в текущую календарную неделю (понедельник — воскресенье) в его часовом поясе. Виджет показывает задачи (все типы), тикеты, лиды и записи справочников, где пользователь — **ответственный** (не соисполнитель); завершённые и отменённые сущности исключаются. Сущности с «Выполнить по» раньше понедельника текущей недели не попадают в виджет; сущности внутри недели остаются в группе соответствующего дня, даже если день уже прошёл. Элементы сгруппированы по дням; для каждого видны тип, название и «Выполнить по»; клик открывает карточку сущности.

## Testable

- Открыть личный дашборд Web под текущим сотрудником → отображается виджет с заголовком «План на текущую неделю»
- Сегодня среда; у пользователя три активные сущности с заполненным «Выполнить по»: задача на среду, тикет на пятницу, лид на понедельник текущей недели; пользователь — ответственный по всем трём; открыть личный дашборд → элементы сгруппированы по дням: лид — в группе понедельника, задача — среды, тикет — пятницы; у каждого видны тип, название и «Выполнить по»
- У пользователя активная задача с «Выполнить по» на четверг текущей недели; пользователь — только соисполнитель, не ответственный; открыть личный дашборд → задача не отображается в виджете
- Пользователь — ответственный за активную задачу с заполненным «Выполнить по» внутри текущей календарной недели → задача отображается в группе соответствующего дня
- Пользователь — ответственный за активный тикет с заполненным «Выполнить по» внутри текущей календарной недели → тикет отображается в группе соответствующего дня
- Пользователь — ответственный за активный лид с заполненным «Выполнить по» внутри текущей календарной недели → лид отображается в группе соответствующего дня
- Пользователь — ответственный за активную запись справочника со сроком действия, попадающим в текущую календарную неделю → запись отображается в группе соответствующего дня
- Активная задача с заполненным «Выполнить по»; пользователь — ответственный → задача присутствует в виджете
- Задача в статусе «Выполнена» с «Выполнить по» в текущей неделе; пользователь — ответственный → задача не отображается в виджете
- Задача в статусе «Отменена» с «Выполнить по» в текущей неделе; пользователь — ответственный → задача не отображается в виджете
- Активная сущность без заполненного «Выполнить по» (или без срока действия для записи справочника); пользователь — ответственный → сущность не отображается в виджете
- Активная сущность с «Выполнить по» строго раньше понедельника текущей календарной недели; пользователь — ответственный → сущность не отображается в виджете
- Активная сущность с «Выполнить по» строго после воскресенья текущей календарной недели; пользователь — ответственный → сущность не отображается в виджете
- Сегодня среда; активная сущность с «Выполнить по» на понедельник той же недели; пользователь — ответственный → сущность остаётся в группе понедельника (день уже прошёл, но внутри текущей недели)
- Элементы виджета с «Выполнить по» на разные дни текущей недели → сгруппированы по дням недели (отдельные группы для каждого дня с элементами)
- Для каждого элемента в виджете → отображаются тип сущности, название и значение «Выполнить по»
- Нажать на элемент в виджете → открывается карточка соответствующей сущности
- Активная задача любого типа (`task`, `meeting`, `agreement`, `acquaintance`, `agreement_task`) с заполненным «Выполнить по» в текущей неделе; пользователь — ответственный → задача отображается в виджете
- Границы текущей календарной недели (понедельник 00:00 — воскресенье 23:59) → определяются в часовом поясе текущего пользователя
- Открыть личный дашборд; в виджете есть элементы на сегодня → заголовок группы дня отображается как «Сегодня»
- В виджете есть элементы на завтра → заголовок группы дня отображается как «Завтра»
- В виджете есть элементы на другой день текущей недели (не сегодня и не завтра) → заголовок группы отображается полным названием дня недели (например «Пятница»)
- Элемент с «Выполнить по» (не встреча с диапазоном времени) → срок отображается в формате «До DD.MM.YYYY, HH:MM»
- Встреча с диапазоном времени «Выполнить по» → срок отображается в формате «До DD.MM.YYYY, HH:MM-HH:MM»
- Тикет в виджете → бейдж типа отображает текст «Тикет»
- Задача в виджете → бейдж типа отображает текст «Задача»
- Лид в виджете → бейдж типа отображает текст «Лид»
- Встреча в виджете → бейдж типа отображает текст «Встреча»
- Запись справочника в виджете → бейдж типа отображает текст «Запись в справочнике»
- Заголовок группы дня в виджете → рядом со стрелкой; клик по заголовку сворачивает или разворачивает список элементов группы
- Развёрнутый виджет с количеством элементов, превышающим видимую область → появляется вертикальная прокрутка с тонким скроллбаром
- Заголовок виджета «План на текущую неделю» → слева от текста отображается иконка calendar-check
