Настраиваемый ИИ-сотрудник workspace при ответе сначала использует данные Upservice в рамках прав пользователя и свою базу знаний; при достаточности этих данных интернет не запрашивается. Если данных недостаточно или пользователь явно просит внешние/актуальные сведения, ИИ-сотрудник сам определяет необходимость интернета и перед поиском явно запрашивает разрешение. Поиск выполняется только после согласия, только по публичным источникам без авторизации и без изменяющих действий во внешних системах. Фрагменты ответа помечаются «Из Upservice» или «Из интернета» (с кликабельной ссылкой на источник); при отсутствии информации — честное «не нашёл» без выдуманных фактов.

## Testable

- Пользователь спрашивает данные, доступные в Upservice в рамках его прав (например телефон контакта «ООО Ромашка»), и в базе знаний ИИ-сотрудника нет отдельной записи по этому объекту → ответ содержит данные из Upservice с пометкой «Из Upservice»; поиск в интернете не выполняется; разрешение на интернет не запрашивается
- Данных Upservice и базы знаний достаточно для ответа на запрос → поиск в интернете не выполняется; разрешение на интернет не запрашивается
- Данных Upservice и базы знаний недостаточно для ответа, либо в запросе явно указана потребность во внешних или актуальных данных (например «Найди в интернете актуальные новости…») → ИИ-сотрудник перед обращением в интернет явно запрашивает у пользователя разрешение на поиск в интернете
- ИИ-сотрудник запросил разрешение на интернет-поиск, пользователь согласился → выполняется поиск в интернете; фрагменты ответа из интернета помечены «Из интернета» и содержат кликабельную ссылку на источник
- ИИ-сотрудник запросил разрешение на интернет-поиск, пользователь отказал → поиск в интернете не выполняется; ответ строится только на данных Upservice и базы знаний, если их достаточно; если недостаточно — сообщается об отсутствии данных без выдуманных фактов
- После поиска в Upservice и (при согласии) в интернете информации нет → ИИ-сотрудник сообщает, что не нашёл информацию; в ответе нет неподтверждённых фактов
- Фрагменты ответа, полученные из данных Upservice или базы знаний ИИ-сотрудника → помечены «Из Upservice»
- Поиск в интернете (после согласия) → выполняется только по публичным источникам без авторизации и не включает действия, меняющие данные или состояние во внешних системах
