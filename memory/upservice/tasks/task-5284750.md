## Description

## User Story

Как пользователь Upservice,
я хочу фильтровать контакты и лиды по контрагенту,
чтобы быстро видеть записи, связанные с нужной компанией.

## Acceptance Criteria

1. На странице «Клиенты → Контакты и чаты» доступен фильтр «Контрагент».
2. На странице «CRM» в панели фильтров доступен фильтр «Контрагент».
3. В фильтре «Контрагент» можно выбрать одного или нескольких контрагентов.
4. При выбранных контрагентах на «Контакты и чаты» отображаются только контакты, связанные хотя бы с одним из выбранных контрагентов.
5. При выбранных контрагентах на странице «CRM» на канбане отображаются только лиды, связанные хотя бы с одним из выбранных контрагентов.
6. Фильтр «Контрагент» сочетается с другими активными фильтрами и поиском на той же странице.
7. Если в фильтре «Контрагент» ничего не выбрано, список контактов и канбан лидов на соответствующих страницах работают как сейчас.

## Examples

### Example 1. Один контрагент на «Контакты и чаты»

**Предусловия:** В воркспейсе есть контрагент «ООО Ромашка» и три контакта: два связаны с «ООО Ромашка», один — без контрагента.

**Действие:** Пользователь открывает «Контакты и чаты» и в фильтре «Контрагент» выбирает «ООО Ромашка».

**Ожидаемый результат:** В списке остаются два контакта, связанных с «ООО Ромашка». Контакт без контрагента не отображается.

### Example 2. Несколько контрагентов в CRM

**Предусловия:** На канбане CRM есть лиды, связанные с «ООО Ромашка», «ИП Иванов» и без контрагента.

**Действие:** Пользователь на странице «CRM» в панели фильтров выбирает «ООО Ромашка» и «ИП Иванов».

**Ожидаемый результат:** На канбане видны лиды, связанные с «ООО Ромашка» или «ИП Иванов». Лиды без контрагента скрыты.

### Example 3. Сброс фильтра

**Предусловия:** На «Контакты и чаты» активен фильтр «Контрагент» с выбранным «ООО Ромашка».

**Действие:** Пользователь очищает выбор в фильтре «Контрагент».

**Ожидаемый результат:** Отображаются все контакты, доступные пользователю на странице, как до применения фильтра.
