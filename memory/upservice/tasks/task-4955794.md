## Description

**Как** пользователь раздела CRM,

**я хочу** видеть всю историю действий по конкретному Лиду (создание, перемещение между стадиями, редактирование),

**чтобы** отслеживать качество обработки Лида.

**Критерий приемки:**

1. Логи внесены в раздел CRM в файлик логов [https://docs.google.com/document/d/16laqcJKw5b4TBw2ROvITzna9_rLh1qDC-6AXZFgx1Q0/edit?tab=t.0](https://docs.google.com/document/d/16laqcJKw5b4TBw2ROvITzna9_rLh1qDC-6AXZFgx1Q0/edit?tab=t.0)
2. Логи, которые подтягиваются из задач и не относятся к Лиду (их нет в разделе CRM в файле логов), удаляем
3. Логи по меткам (раздел "для всех сущностей" в файле логов) оставляем для Лидов
4. Логи по лиду фиксируются в чате контакта, который привязан к этому лиду.
Если контактов несколько - логи по лиду фиксируются в чатах всех контактов
5. В рамках этой стори исправить текст ошибки на скрине (вместо "данной задачи" нужно "данного лида")
