## Description

Как пользователь,

я хочу настраивать автокопирование или перенос лида в выбранную воронку через правила автоматизации,

чтобы лиды автоматически переносились в другую воронку при переходе на указанный мною статус

## Acceptance Criteria

Реализуем через правило автоматизации:

1. Тип сущности - Лид - **уже будет создан**
2. Триггер - Изменение стадии лида (= лид перешёл на стадию в воронке, включая создание лида на стадии) - **уже будет создан**
3. Условие - Воронка и статус - **уже будет создано**
4. Действие - Создать копию лида - поля Воронка и Статус
Или Сменить воронку и статус лида - поля Воронка и Статус - **уже будет создано**

Логика работы:

при переходе лида в указанный в условии статус:

1. Создается копия лида в указанном статусе
2. Или исходный лид переносится в указанный статус

При повторном входе лида на стадию, для которой условия правила снова совпали, действие повторяется снова
