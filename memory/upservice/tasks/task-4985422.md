## Description

## User story

Как пользователь,
я хочу иметь возможность создавать лида из тикета,
чтобы продолжать работу с контактом, если разовое обращение от него переквалифицируется в долгосрочный лид

## Критерии приёмки

1. В тикете по кнопке Добавить в список сущностей добавляем сущность Лид
2. При нажатии на Лид открывается дровер создания лида c доп полем Воронка (в дровер создания лида из раздела CRM поле Воронка выводить не нужно, дровер редактирования тоже не меняем)
3. В лид сразу прокидывается Название, Описание, Контакт, Ответственный, Метки
4. Обязательно поле - Воронка, содержит список воронок воркспейса
