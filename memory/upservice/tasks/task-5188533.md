## Description

Как пользователь,

я хочу видеть в ленте уведомлений корректные записи о полученных ранее нотификациях именно по лидам,

чтобы иметь возможность просмотреть предыдущие нотификации и перейти по ним в сущность лида

Критерии приемки:

1. Добавляем две нотификации по лидам: id 103 и 105 в файле нотификаций в разделе CRM - выделены красным (в момент наступления "выполнить по" и когда этот срок приближается)
2. При работе с лидом пользователь получает только те нотификации по действиям в лиде, которые прописаны в разделе CRM в файле https://docs.google.com/document/d/1uTg45rIFwQPxf-IELTmchSjZoHwHAlk8/edit. Все лишние нотификации, которые есть в задачах, но нет в лидах, не должны приходить при работе с лидом
3. Нотификации, получаемые по лидам, в таблице у которых не стоит "-" по записи в ленте, фиксируются в ленте уведомлений. Шапка отображается по шаблону ID {id лида} {название лида}. Ссылка ведет на лид. Если нотификация о сообщениях в чате - ссылка ведет на чат с контактом (как и сейчас)

Исправить кейсы:

1. Ссылка из ленты ведет на задачу, не на лид
2. В тексте в ленте "задача", нужно чтобы был "лид"
3. На фронте не отображается в шапке ссылка на лид по шаблону ID {id лида} {название лида}. Ссылка должна вести на лид
4. Аналогично 3 + в тексте нотифы после лида надо чтобы было "ID {id} {название}", сейчас там просто цифры айдишные
