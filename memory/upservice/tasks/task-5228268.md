## Description

## User story

Как сотрудник,
я хочу видеть на личном дашборде план работ на текущую неделю по задачам, тикетам и лидам,
чтобы заранее понимать, что нужно выполнить по дням.

## Контекст и проблема

На личном дашборде (Web) нет единого обзора работ с заполненным сроком «Выполнить по» на текущую календарную неделю. Пользователю приходится искать задачи, тикеты и лиды в разных разделах.

## Выбранное решение

Виджет **«План на текущую неделю»** на личном дашборде (Web) показывает **задачи, тикеты и лиды** текущего пользователя по единым правилам:

- пользователь — **ответственный** (не соисполнитель);
- сущность **активна** (не завершена и не отменена);
- поле **«Выполнить по»** заполнено и попадает в **текущую календарную неделю** (пн–вс, часовой пояс пользователя);
- сущности с «Выполнить по» **раньше понедельника текущей недели** не показываются;
- сущности **внутри текущей недели** остаются в плане **даже если день уже прошёл**.

Элементы **сгруппированы по дням**; для каждого — тип, название, «Выполнить по»; клик открывает карточку сущности.

## Критерии приёмки

1. На личном дашборде (Web) отображается виджет «План на текущую неделю».
2. В виджете показываются задачи, тикеты и лиды по единым правилам отбора.
3. В виджет попадают только сущности, где текущий пользователь — ответственный; сущности, где пользователь только соисполнитель, не отображаются.
4. В виджет попадают только активные сущности; завершённые и отменённые не показываются; для задач из отбора исключаются статусы «Выполнена» и «Отменена».
5. В виджет попадают только сущности с заполненным полем «Выполнить по», дата которого попадает в текущую календарную неделю (понедельник — воскресенье) в часовом поясе пользователя.
6. Сущности без заполненного «Выполнить по» не отображаются в виджете.
7. Сущности с «Выполнить по» строго раньше понедельника текущей недели не отображаются в виджете.
8. Сущности с «Выполнить по» внутри текущей недели отображаются в группе соответствующего дня, даже если этот день уже прошёл.
9. Элементы в виджете сгруппированы по дням недели.
10. Для каждого элемента отображаются: тип сущности, название, значение «Выполнить по».
11. При клике на элемент открывается карточка соответствующей сущности.
12. Отображаются сущности: Задачи (Все типы с заполненным Выполнить по), Тикеты (с заполненным Выполнить по),  Лиды (с заполненным Выполнить по), Записи в справочнике (С заполненным сроком действия справочника) + попадают под текущую календарную неделю)

## Примеры использования

### Пример 1. План на несколько дней недели

**Предусловия:** Сегодня среда. У пользователя три активные сущности с заполненным «Выполнить по»: задача на среду, тикет на пятницу, лид на понедельник текущей недели. Пользователь — ответственный по всем трём.

**Действие:** Пользователь открывает личный дашборд.

**Ожидаемый результат:** В виджете элементы сгруппированы по дням: лид — в группе понедельника, задача — среды, тикет — пятницы. У каждого элемента видны тип, название и «Выполнить по».

### Пример 2. Сущность вне отбора

**Предусловия:** У пользователя активная задача с «Выполнить по» на четверг текущей недели. Пользователь — только соисполнитель, не ответственный.

**Действие:** Пользователь открывает личный дашборд.

**Ожидаемый результат:** Задача не отображается в виджете.
