## Description

Как пользователь,

я хочу добавить в лид несколько контактов (больше одного),

чтобы у меня была возможность вести коммуникацию по одному лиду с несколькими контактами

Критерии примки:

1. Поле Контакт остается обязательным
2. В поле Контакт можно добавить более одной сущности
3. При открытии лида открывается чат с 1 в списке контактов (всегда один и тот же контакт)
4. В правой части карточки в верху чата отображаются аватарки всех прикрепленных контактов, есть возможность переключаться между контактами лида через выпадающий список
5. При переключении на другой контакт чат в лиде подменяется на чат с новым контактом, контактная информация отображается по новому контакту
6. Убрать иконку канала с авы контакта(-ов) в чате лида
