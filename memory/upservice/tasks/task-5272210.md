## Description

## User Story

Как пользователь,
я хочу в разделе «Правила автоматизации» настроить сценарии с отложенной отправкой сообщения в чат контакта при изменении стадии лида,
чтобы follow-up контактам планировался автоматически для каждой нужной стадии воронки без ручной настройки для каждого лида.

## Acceptance Criteria

1. В настройках workspace в разделе «Правила автоматизации» добавляем новый **тип сущности** = Лид
2. Для **триггера** «Изменение стадии лида» (лид перешёл на стадию в воронке, включая создание лида на стадии) в **условиях** доступны воронка и стадия воронки; все заданные условия проверяются с логикой «И».
3. Для триггера «Изменение стадии лида» в **действиях** доступно «Отложенное сообщение в чат контакта» с полями: текст сообщения (обязательно), относительная задержка в днях и часах (минимум 1 минута)**.**
4. При срабатывании правила (=лид перешел на стадию) система планирует одно разовое отложенное сообщение (повторяемость «Никогда») в чат контакта(-ов), связанного с лидом; отправитель — ответственный по лиду на момент срабатывания правила; чат - по единственному каналу если он всего 1 и доступен для исходящих сообщений либо, если их несколько, чат по каналу, который доступен для исходящих сообщений контакту и по которому велась последняя коммуникация с ним.
5. Запланированное и отправленное сообщение отображается и доставляется как при ручном отложенном сообщении контакту (story 4985393): в чате контакта и лиде.
6. На момент планирования отложенного проверяются права ответственного по лиду на исходящее сообщение контакту по каналу из действия — как при ручной отправке. При недостаточных правах на планировании отложенное сообщение не создаётся.
7. Запланированное сообщение не отменяется автоматически ни при каких условиях, только если пользователь вручную удалил его из чата с контактом.
8. При повторном входе лида на стадию, для которой условия правила снова совпали, таймер запускается заново по актуальным настройкам правила и планируется новое отложенное сообщение.
9. Изменения текста или задержки применяются только к новым срабатываниям
10. Выключение правила не отменяет ожидающие отправки, запланированные этим правилом.
11. Включение или изменение правила не планирует сообщения для лидов, которые уже на стадии без нового перехода на неё.
12. Настройка правил автоматизации доступна пользователям с правами управления правилами автоматизации в workspace.
