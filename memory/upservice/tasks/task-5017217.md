## Description

**Как** пользователь Upservice,
**я хочу**, чтобы AI-сотрудник самостоятельно обрабатывал поступающие ему файлы и анализировал их содержимое,
**чтобы** он вел себя как обычный сотрудник: изучал документы, мог переказать содержание, ответить на вопрос по содержимому

Критерии приемки:

1. При отправке AI-сотруднику текстового файла (**док, пдф, таблицы**) он автоматически открывает и обрабатывает его содержимое с использованием LLM.
2. После завершения анализа AI подтверждает ознакомление с файлом
3. При последующих запросах пользователя о содержимом файла в рамках данного чата AI дает информацию по этому файлу через **кратковременную память**
4. По отдельному запросу в этому же чате AI может выдать краткое саммари по содержанию файла (= должен уметь делать саммари, но только при доп запросе)
5. Если при анализе документов возникает ошибка (например, ИИ еще не умеет обрабатывать такой тип файла или файл поврежден) или не понятен контекст, AI сообщает об этом отправителю файла и не начинает обработку.
6. Если в одном запросе несколько файлов, ИИ анализирует файлы по отдельности, подтверждает ознакомление с каждым файлом
7. По запросу может выдать саммари отдельно по каждому файлу

**Примеры**:

Кейс 1.

AI получает PDF-файл:«Регламент работы AI-сотрудника»

AI проверяет свой доступ к файлу (по идее всегда будет, так как файл отправляется в чат сущности куда у ИИ уже есть доступ), открывает документ, изучает его содержимое, подтверждает ознакомление. Если я спрошу "о чем этот документ?" новым запросом, он подготовит саммари. Может ответить на вопросы по файлу в камках текущего чата

Кейс 2. Не умеет обрабатывать такой тип файлов или файл поврежден

AI отправили файл, который AI не может обработать.

AI уведомляет инициатора:«Не удалось ознакомиться с документом. Я еще не научился обрабатывать этот тип файла / Файл поврежден»
