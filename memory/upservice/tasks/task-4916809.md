## Description

Как пользователь раздела CRM, я хочу видеть сумму стоимости лидов на каждом из статусов и итого по воронке, чтобы оценивать планируемую выручку.

## Acceptance Criteria

1. По каждой колонке в режиме канбан под названием этапа отображается сумма значений по полю Сумма всех лидов этой воронки, которые находятся на данном статусе
2. В верху страницы отображается текст «Найдено N лидов на сумму X *символ* *валюты*», где N = кол-во лидов в этой воронке, X = сумма по полю Сумма во всех лидах этой воронки
3. При применении фильтров значение суммы и по этапам, и по всей воронке пересчитывается в соответствии с отобранными по фильтрам лидами
4. Переиспользуем текущий эндпоинт на валюты (~165 стран); вынести в список валют на канбане + поиск по полю валюта; топ валют СНГ и новых рынков вверху: RUB, USD, EUR, CNY, KZT, BYN, ZAR, MYR, UZS, AMD, PHP, KES
5. Конверсия итоговой суммы по этапам и итого по воронке рассчитывается по API ExchangeRate-API
6. Тестируем конвертацию основных пар: USD↔RUB/BYN/EUR; BYN↔RUB/USD/EUR; RUB↔USD/BYN/EUR; EUR↔RUB/BYN/USD
7. По умолчанию сумма на канбане в USD; выбор валюты сохраняется per-user до смены
8. Для лидов на группах стадий new и in progress сумма считается по курсу на текущую дату
9. Для лидов на завершенных стадиях сумма считается по курсу на дату перемещения на эту стадию
10. Символ валюты (или сокращённое название при отсутствии символа) в строке итого, сумме по столбцу, компактной и развёрнутой карточке лида
