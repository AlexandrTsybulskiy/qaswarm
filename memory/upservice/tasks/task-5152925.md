## Description

Как сотрудник, я хочу видеть ближайшие встречи и быстро подключаться к ним, чтобы не пропускать мероприятия и не искать ссылку в календаре.

**Критерии приемки:**

1. Виджет показывает ближайшие встречи текущего пользователя.
2. Отображаются встречи на сегодня и следующий календарный день.
3. Для встречи показываются:

- дата;
- время;
- название;
- участники;
- длительность.

4. Для онлайн-встречи отображается кнопка «Подключиться».
5. Кнопка открывает ссылку встречи в новой вкладке.
6. Для встречи без ссылки кнопка «Подключиться» не отображается.
7. «Смотреть календарь» открывает календарь пользователя.
8. При отсутствии встреч показывается пустое состояние.

### Логика расчёта

Выбираются события календаря, для которых:

- текущий пользователь является участником;
- время окончания встречи больше текущего времени;
- начало встречи находится в пределах сегодня и завтра.

Сортировка — по времени начала по возрастанию.
