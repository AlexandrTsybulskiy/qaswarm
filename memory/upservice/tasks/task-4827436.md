## Description

## User story

Я, как администратор канала «Чат на сайте»,
хочу самостоятельно определять, обязательно ли клиенту указывать Email перед началом общения,
чтобы настраивать форму виджета под процессы своей компании.

## Критерии приёмки

1. В настройках канала «Чат на сайте» для поля Email добавлен переключатель «Обязательное поле Email».
2. Переключатель доступен при создании и редактировании виджета.
3. Если переключатель включён: поле Email помечается как обязательное; клиент не может начать чат или отправить форму без заполнения поля; при попытке продолжить без Email отображается сообщение об обязательности поля; введённое значение проверяется на соответствие формату Email.
4. Если переключатель выключен: клиент может начать чат без заполнения Email; поле продолжает отображаться в форме, но не помечается как обязательное; если клиент указал Email, значение всё равно проверяется на корректность формата.
5. Значение настройки сохраняется отдельно для каждого виджета.
6. После сохранения настроек выбранное состояние переключателя сохраняется при повторном открытии формы редактирования.
7. Изменение настройки применяется к клиентскому виджету после сохранения или публикации изменений.
8. Для уже существующих виджетов переключатель по умолчанию выключен, чтобы после релиза клиенты не столкнулись с неожиданным обязательным заполнением Email.

Форма для ввода email доступна: при нажатии на кнопку «Заказать обратный звонок»; когда пользователь открывает виджет в нерабочее время.
