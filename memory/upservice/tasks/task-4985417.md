## Description

## User story

Как пользователь,
я хочу указывать причину перевода статуса лида,
чтобы собирать аналитику по причинам потерянных клиентов

## Критерии приёмки

1. На странице настроек CRM под КОНЕЧНЫМ статусом отображается переключатель "Собирать причину провала"
2. При активации переключателя пользователю отображается список "Причины провала", где он может задать значения списка, где каждое значение = одна причина перевода
3. При переносе лида на стадию ,где активен переключатель,  пользователю высвечивается модальное окно с текстом "Укажите причину провала" и полем типа список с вариантами значений
4. Выбранное значение причины фиксирует в виде лога: ФИО кто измени: Причина + дата и время
5. Если активен переключатель, пользователь не может переместить на соответствующий статус лид без обязательного указания причины
