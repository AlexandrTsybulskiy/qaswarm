## Description

Как сотрудник, я хочу видеть внесённые трудозатраты за сегодня, неделю и месяц, чтобы контролировать полноту учёта своего рабочего времени.

**Критерии приемки:**

1. Виджет показывает трудозатраты:

- а сегодня;
- за текущую неделю;
- за текущий месяц.

2. Значения отображаются в часах и минутах.
3. График отображает динамику Фактических трудозатрат по датам. Можно выбрать период отображения данных для графика - Неделя (=текущая неделя) или Месяц (=текущий месяц). По умолчанию активен фильтр Неделя
4. Учитываются только трудозатраты текущего пользователя.
5. При отсутствии данных отображаются нулевые значения и пустое состояние графика.

### Логика расчёта

Суммируется продолжительность всех записей Фактических трудозатрат текущего пользователя:

- сегодня — с начала текущего дня;
- неделя — с начала текущей календарной недели;
- месяц — с первого дня текущего месяца.
