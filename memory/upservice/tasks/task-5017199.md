## Description

**Как** пользователь Upservice,

**я хочу**, чтобы AI-сотрудник по запросу мог найти, в каком файле хранится указанная в запросе информация,

**чтобы** облегчить поиск по файлам внутри системы

Критерии приемки:

1. Обучить AI искать файлы по разделу Мой диск - это семантический поиск по содержимому и названию файлов в рамках текущего воркспейса. Запрос уходит на сервер, сервер обращается к отдельному поисковому сервису, получает релевантные файлы и возвращает их пользователю с учётом прав доступа
2. ИИ может искать файлы по

- названию
- содержимому

3. ИИ сотрудник может искать и давать информацию только по тем файлам, к которым у него есть доступ на просмотр
4. По возможности будет реализовано - поиск сочетается с фильтрами: тип связи (с задачами/справочниками и др), автор, теги, тип, дата добавления и срок актуальности
5. Результат - прикрепленный файл(-ы), отсортированные по релевантности (поиск так и выдает файлы при наличии запроса)
6. Если в доступных файлах нет запрашиваемой информации, ИИ сообщит об этом
7. Если при поиске документов возникает ошибка (например, файл поврежден, или при запросе был сбой поискового сервиса) или не понятен контекст, AI сообщает об этом пользователю и не начинает обработку до получения доступа к содержимому файлов.

Уточнение

1. Новые и изменённые файлы попадают в поиск не мгновенно, а после фоновой индексации.

Примеры

Кейс 1

"Пришли мне файл, в котором расписан регламент работы AI-сотрудника"

AI ищет совпадения по названию и тексту документов, к которым у него есть доступ, и выдает соответствующие файлы в качестве ответа

Кейс 2

"В каком документе хранятся инструкции по работе с базой знаний?"

AI ищет совпадения по названию и тексту документов, к которым у него есть доступ, и выдает соответствующие файлы в качестве ответа

Кейс 3

"У нас где-то лежит файл, в котором описан регламент работы AI-сотрудника."

AI ищет по названиям и контексту файлы, к которым у него есть доступ, по этой теме, выдает соответствующие файлы в качестве ответа

Вторым запросом "что из себя представляет этот регламент?"

просматривает файлы и выдает мне ответ на вопрос
