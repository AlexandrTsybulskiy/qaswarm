## Description

[Story] — Подключение Яндекс Диска в интеграциях воркспейса

## User Story

Как оунер воркспейса,
я хочу подключить Яндекс Диск в «Настройки → Интеграции → Интеграции воркспейса»,
чтобы в воркспейсе можно было подключить Яндекс Диск и не держать его одновременно с Google Диском.

## Acceptance Criteria

1. В «Настройки → Интеграции → Интеграции воркспейса» у оунера есть карточка Яндекс Диска: подключить, показать подключённый аккаунт, отключить с подтверждением.
2. Подключить и отключить Яндекс Диск может только оунер воркспейса. Сотрудник, который не оунер, не подключает Яндекс Диск: блок «Интеграции воркспейса» недоступен для подключения, как сейчас.
3. Одновременно подключён только один диск воркспейса — Google Диск или Яндекс Диск. Если ни один не подключён, оунер может подключить любой из них. Если один подключён, подключить второй нельзя, пока первый не отключён.
4. При попытке подключить второй диск первый автоматически не отключается.
5. После подтверждённого отключения Яндекс Диска интеграция снята; воркспейс без подключённого диска воркспейса — как сейчас в этом состоянии.
6. Возможность загружать файлы в подключенный яндекс диск
