## User Story

Как сотрудник с подключённой синхронизацией Google Calendar,
я хочу видеть в «Календаре встреч» Upservice не только задачи-встречи,
но и остальные события из Google Calendar (в т.ч. из смерженных календарей),
чтобы понимать реальную занятость и не планировать поверх чужих/сервисных блоков времени.

---

## Контекст / AS IS

При включённой синхронизации с Google Calendar в календаре встреч отображаются только:

- задачи-встречи, созданные в Upservice;
- события Google, которые синхронизированы и созданы как задачи-встречи.

Не отображаются:

- сущности Google, которые не являются встречами (Out of office, Focus time, Working location и т.п.);
- обычные Event из других (смерженных) календарей владельца, если по ним не создана задача Upservice.

---

## Типы сущностей Google Calendar (в scope)

1. **Event** — обычное событие/встреча Google
2. **Task** — задача Google Calendar
3. **Out of office**
4. **Focus time**
5. **Working location**
6. **Appointment schedule**

Плюс: события из **смерженных/дополнительных календарей** владельца подключённого Google-аккаунта.

---

## Цель / TO BE

При синхронизации показывать в календаре встреч Upservice все релевантные события Google владельца календаря, визуально отличая их от задач-встреч Upservice.

---

## Функциональные требования

### FR-1. Синхронизация и отображение

1. При активной синхронизации с Google Calendar система получает и отображает события всех типов из scope (см. выше).
2. События из смерженных календарей владельца также отображаются в сетке календаря встреч.
3. Отображение работает в представлениях День / Неделя / Месяц (как минимум в тех же view, где сейчас показываются встречи).

### FR-2. Разделение сущностей

1. **Встреча Upservice** (задача kind=meeting, созданная в Upservice или синхронизированная как задача) — текущий визуал (оранжевый стиль).
2. **Событие Google без задачи Upservice** — отдельный визуальный стиль (не оранжевый), без превращения в задачу Upservice по умолчанию.
3. Специальные типы Google (Out of office / Focus time / Working location / Appointment schedule / Task) имеют различимые стили или метки типа.

### FR-3. Визуальная дифференциация (по дизайну)

| Тип | Визуал |
|---|---|
| Встреча Upservice | Оранжевая карточка (как сейчас), с аватаром/иконкой задачи |
| Event Google (в т.ч. из смерженного календаря) | Голубой стиль, подпись источника (Google · название календаря), без аватара исполнителя Upservice |
| Focus time | Сиреневый стиль, тип читается как Focus time |
| Out of office | Серый фон + штриховка + пунктирная обводка |
| Working location | Мятный стиль + пунктир, показывает локацию |
| Task / Appointment schedule | Отдельный стиль/лейбл (уточнить в финальном UI; в proposal заложена логика «не встреча Upservice») |

### FR-4. Поведение при клике / взаимодействии

1. Клик по **встрече Upservice** — открывает карточку задачи/встречи Upservice (как сейчас).
2. Клик по **событию Google без задачи Upservice** — открывает read-only просмотр деталей события (название, время, тип, календарь-источник). Не создаёт задачу автоматически.
3. События Google **не участвуют** в статусах/согласованиях/worklog Upservice как задачи, пока пользователь явно не конвертирует их (если конвертация будет в scope отдельной задачей — вне текущего MVP).

### FR-5. Данные на карточке

Минимум на карточке в сетке:

- название;
- время (или «весь день»);
- тип / источник (Google + имя календаря при наличии).

### FR-6. Конфликты и пересечения

События Google участвуют в визуальном пересечении слотов так же, как встречи (чтобы занятость была видна).

---

## Нефункциональные / ограничения

1. Не ломать текущую синхронизацию встреч ↔ Google Event.
2. Не создавать дубли задач Upservice для OOO / Focus / Working location / чужих календарных Event.
3. Учитывать права: показываем события доступные через подключенный Google-аккаунт пользователя.
4. Производительность: подгрузка событий не должна заметно деградировать открытие календаря.

---

## Out of scope (на сейчас)

- Редактирование/удаление Google-событий из Upservice
- Двусторонняя запись OOO/Focus/Working location из Upservice в Google
- Автоконвертация Google Event → задача-встреча Upservice

---

## Acceptance Criteria

1. При подключённом Google Calendar в сетке видны Event / Out of office / Focus time / Working location (и при наличии — Task, Appointment schedule).
2. События из смерженного календаря владельца отображаются.
3. Встречи Upservice визуально отличаются от Google-событий (другой цвет/стиль).
4. Google-события без задачи Upservice **не** создают задачу в списке задач.
5. Клик по Google-событию открывает детали, а не карточку задачи Upservice.
6. UI соответствует согласованному дизайну (ссылки выше).
