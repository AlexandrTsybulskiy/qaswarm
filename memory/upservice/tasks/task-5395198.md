## Description

[Story] - Массовый импорт контактов ИИ сотрудником

## User Story

Как пользователь Upservice, я хочу передать ИИ-сотруднику файл с контактами в произвольной структуре, чтобы он самостоятельно разобрал данные, преобразовал их в формат импорта Upservice и создал контакты в системе.

## Acceptance Criteria

1. Пользователь может передать ИИ-сотруднику файл с контактами без предварительной подготовки по шаблону Upservice.
2. ИИ сотрудник определяет структуру данных и сопоставляет исходные поля с существующими полями контакта Upservice.
3. ИИ сотрудник преобразует данные к актуальному формату массового импорта, включая обязательные поля и допустимые значения.
4. ИИ сотрудник не придумывает отсутствующие данные и запрашивает уточнение при неоднозначном сопоставлении.
5. ИИ сотрудник предоставляет результат подготовки и запрашивает подтверждение перед массовым созданием контактов.
6. После подтверждения ИИ сотрудник создаёт контакты с соблюдением своих прав.
7. ИИ сотрудник сообщает точный результат импорта: успешно созданные, пропущенные и неуспешные записи с причинами.
8. Повторный импорт после частичной ошибки не приводит к повторному созданию уже импортированных контактов.
