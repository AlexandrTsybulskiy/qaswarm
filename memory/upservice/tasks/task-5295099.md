## Description

## User Story

Как маркетолог / sales-менеджер,
я хочу, чтобы лид в воронке «Воронка квалификации» автоматически переходил со статуса «Лид» на статус «MQL» при достижении порога скоринга,
чтобы не переносить квалифицированные лиды вручную на Kanban.

## Acceptance Criteria

1. После пересчёта **итогового балла скоринга** лида (registered/form scoring) система проверяет правило автоперехода статуса воронки.
2. Если лид в воронке с названием **«Воронка квалификации»** (точное совпадение), на статусе **«Лид»** (точное совпадение), итоговый балл скоринга **≥ 50** и для лида **нет запрета MQL** — статус воронки меняется на **«MQL»**.
3. Смена статуса выполняется так же, как при ручном перемещении лида на статус «MQL» на Kanban или в карточке лида.
4. Если итоговый балл скоринга **< 50** или для лида действует **запрет MQL**, система **не переводит** лид на статус «MQL» **автоматически**; пользователь с правом смены статуса воронки может перевести лид на «MQL» **вручную**.
5. Если лид уже на статусе **«MQL»** или на статусе **дальше «MQL»** в этой воронке — статус не меняется при пересчёте скоринга.
6. Если после перехода на «MQL» итоговый балл скоринга падает **ниже 50** — статус воронки **автоматически не откатывается**; откат возможен только вручную.
7. Лиды в **других воронках** или на **других статусах** воронки «Воронка квалификации» этим правилом не затрагиваются.
8. Если в workspace **нет** воронки «Воронка квалификации» или статусов «Лид» / «MQL» — система не меняет лиды и **не показывает ошибку**.
9. При автоматическом изменении статуса воронки в **истории действий** лида отображается соответствующая **запись в логе**.

## Examples

### Пример 1. Достижение порога — автопереход

**Предусловия:** Лид в воронке «Воронка квалификации» на статусе «Лид». Итоговый балл скоринга после пересчёта — **52**. Запрета MQL нет.

**Действие:** Система пересчитывает итоговый балл скоринга лида.

**Ожидаемый результат:** Статус воронки — «MQL». Лид в колонке «MQL» на Kanban. В истории действий лида — запись об автоматическом изменении статуса.

### Пример 2. Запрет MQL — автопереход не срабатывает, ручной возможен

**Предусловия:** Лид из формы в воронке «Воронка квалификации» на статусе «Лид». Итоговый балл скоринга — **55**. Для лида действует запрет MQL («Не является потенциальным покупателем»).

**Действие:** Система пересчитывает итоговый балл скоринга лида.

**Ожидаемый результат:** Статус воронки автоматически остаётся «Лид».

**Дополнительно:** Менеджер с правом смены статуса воронки вручную переводит лид на «MQL» — статус меняется; в истории действий — запись о ручной смене статуса (не автоматическая).

### Пример 3. Падение балла после MQL — без автоматического отката

**Предусловия:** Лид в воронке «Воронка квалификации» уже на статусе «MQL». Итоговый балл скоринга после пересчёта — **38**.

**Действие:** Система пересчитывает итоговый балл скоринга лида.

**Ожидаемый результат:** Статус воронки автоматически остаётся «MQL».

### Пример 4. Балл < 50 — автопереход не срабатывает, ручной возможен

**Предусловия:** Лид в воронке «Воронка квалификации» на статусе «Лид». Итоговый балл скоринга после пересчёта — **42**. Запрета MQL нет.

**Действие:** Система пересчитывает итоговый балл скоринга лида.

**Ожидаемый результат:** Статус воронки автоматически остаётся «Лид». Менеджер вручную переводит лид на «MQL» — статус меняется.
