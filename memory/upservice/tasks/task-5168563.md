## Description

Как пользователь Upservice,
я хочу искать информацию по сообщениям в чатах сущностей,
чтобы быстро находить нужные обсуждения и решения без необходимости вручную просматривать переписки.

AC

1. В системе добавлена возможность общего поиска по системе (по сущностям и по сообщениям в чатах сущностей). Плейсхолдер: Поиск по системе
2. Результаты поиска отображаются текущему пользователю согласно его правам доступа. Пользователь не может найти или увидеть сообщения из сущностей, к которым у него нет доступа.
3. Поиск выполняется через поисковый сервис с использованием гибридного поиска:

- полнотекстовый поиск по сущностям;
- семантический поиск по смыслу сообщения (vector search).

6. Поиск доступен по сообщениям следующих разделов сущностей:

- Беседы;
- Задачи и их чаты;
- Справочники и их чаты;
- Тикеты и их чаты;
- Лиды и их чаты.
- Контакты и их чаты

7. Каждый результат поиска должен содержать:

- тип сущности
- название сущности
- ссылку на переход в сущность
- ответственного\управляющего (для справочника)
- id сущности ( где возможно)
- TBD

7. Логика поиска

- точное совпадение слов;
- частичное совпадение;
- поиск по смыслу сообщения.

8. Результаты отображаются по релевантности, max кол-во - tbd. При одинаковой релевантности -

- более новые сущности в которых были апдейты;

9. Если подходящих сущностей нет, система отображает заглушку "По вашему запросу ничего не найдено."
10. В системе добавлена поддержка горячей клавиши для быстрого открытия глобального поиска. При нажатии сочетания клавиш система открывает модальное окно поиска.:Windows / Linux: Ctrl+K, macOS: Command+K
11. Горячая клавиша должна работать независимо от текущего раздела системы.
12. При открытии окна поиска курсор автоматически устанавливается в поле ввода поискового запроса.
13. Если окно поиска уже открыто, повторное нажатие горячей клавиши не создает дополнительное окно.
14. Нажатие клавиши Esc закрывает окно поиска.
15. Горячая клавиша не должна конфликтовать с существующими системными действиями внутри приложения.
16. В интерфейсе рядом с полем поиска отображается подсказка о доступной комбинации клавиш
