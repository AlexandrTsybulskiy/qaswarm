## Description

**Как** пользователь,

**я хочу** видеть наличие лидов по контакту, в карточке которого я нахожусь,

**чтобы** по контакту отображалась полная информация из системы

**Критерии приемки:**

1. В карточке контакта в правой часте экрана по аналогии с разделом Тикеты добавлен раздел Лиды
2. При раскрытии этого раздела пользователю отображаются все лиды, у которых в поле Контакт указан данный контакт
3. Если таких лидов нет, пишем "Лиды не найдены"
4. При нажатии на карточку лида в новом окне открывается данный лид
