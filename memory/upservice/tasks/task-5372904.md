## Description

[Story] — Индикатор неотвеченного вызова у лида

## User Story

Как пользователь Upservice, работающий с лидами,
я хочу видеть лидов с неотвеченным вызовом,
чтобы понимать, кому требуется перезвонить.

## Acceptance Criteria

1. Если у лида есть неотвеченный вызов, на карточке лида в CRM Kanban отображается специальная иконка.
2. Если у лида есть неотвеченный вызов, в карточке лида на странице detail отображается специальная иконка.
3. После первого отправленного сообщения со стороны Upservice специальная иконка у лида исчезает.
4. Если у лида несколько неотвеченных вызовов, специальная иконка также исчезает после первого отправленного сообщения со стороны Upservice.
5. В рамках изменения сохраняются колонки Kanban по стадиям, карточки лидов с плашкой стадии, split-view карточки лида и плашка стадии в заголовке карточки лида.

## Examples

### Example 1

**Предусловия:** У лида есть один неотвеченный вызов.
**Действие:** Пользователь открывает CRM Kanban.
**Ожидаемый результат:** На карточке лида отображается специальная иконка.

### Example 2

**Предусловия:** У лида есть один неотвеченный вызов.
**Действие:** Пользователь открывает карточку лида в detail.
**Ожидаемый результат:** В карточке лида отображается специальная иконка.

### Example 3

**Предусловия:** У лида есть один неотвеченный вызов, и специальная иконка отображается.
**Действие:** Пользователь отправляет первое сообщение со стороны Upservice.
**Ожидаемый результат:** Специальная иконка у лида исчезает.

### Example 4

**Предусловия:** У лида есть несколько неотвеченных вызовов, и специальная иконка отображается.
**Действие:** Пользователь отправляет первое сообщение со стороны Upservice.
**Ожидаемый результат:** Специальная иконка у лида исчезает.
