## Description

Как пользователь,

я хочу видеть обновленный дизайн календаря при заполнении поля дата и время,

чтобы удобнее выставлять дату и время для встреч и иных событий, планируемых через Upservice

Критерии приемки:

1. По всей системе при нажатии на поле дата и время открывается обновленный вид календаря: [https://ant.design/components/date-picker](https://ant.design/components/date-picker)
2. Заменяем компонент календаря и для диапазона дат, и для единичного поля дата и время
3. В календарях отображаются пресеты времени типо "сегодня", "завтра", "текущий месяц" и др
