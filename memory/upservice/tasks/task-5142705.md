## Description

Как пользователь Upservice,
я хочу, чтобы в системе была возможность автоматического создания уникальных вариантов текста при подготовке массовой рассылки,
чтобы снизить вероятность распознавания сообщений как массовой рассылки, повысить доставляемость и сделать коммуникацию более естественной.

АС

1. При создании массовой рассылки пользователь может сгенерировать пул сообщений ( логика Spintax)
2. Кнопка Генерировать уникальные сообщения отображается после того, как пользователь ввел минимум 30 символов в поле "Сообщение"
3. По клику система передает исходный текст сообщения в LLM для генерации вариантов.
4. AI создает 10 альтернативных вариантов сообщения, сохраняя исходный смысл и цель коммуникации. AI изменяет формулировки, используя синонимы, перестановку предложений, изменение структуры текста и другие языковые приемы.
5. При отправке каждому получателю система выбирает один из сгенерированных вариантов сообщения.
6. Один и тот же вариант может использоваться для нескольких получателей..
7. AI не изменяет

- ссылки;
- переменные и шаблоны подстановки;
- контактные данные;
- промокоды;

10. Перед отправкой пользователь может просмотреть  примеры сгенерированных вариантов сообщения. Система отображает первые 3 варианта, а далее по кнопке Показать все, можно развернуть и проверить все варианты.
11. Пользователь может повторно сгенерировать варианты до начала рассылки ( безлимитное кол-во раз).
