## Description

## User Story

Как пользователь Upservice,
я хочу поручить ИИ-сотруднику создать пользовательский отчёт прямо в диалоге,
чтобы получить аналитику там, где возник вопрос, и открыть отчёт повторно из раздела «Отчёты».

## Acceptance Criteria

1. ИИ-сотрудник создаёт один пользовательский отчёт по запросу пользователя в любом чате, где доступен диалог с ним.
2. За один запрос обрабатывается не более одного отчёта.
3. После успешного создания ИИ-сотрудник отправляет в том же чате сообщение с названием отчёта и действием «Открыть отчёт»; по действию открывается страница этого отчёта.
4. Созданный отчёт появляется во вкладке «Пользовательские отчёты» раздела «Отчёты» workspace компании и доступен пользователю, сделавшему запрос.
5. Если параметры отчёта (метрики, период, срез, тип визуализации и т.п.) нельзя однозначно определить, ИИ-сотрудник задаёт уточняющие вопросы и не создаёт отчёт до получения ответа.
6. Отчёт содержит только данные, которые пользователь, сделавший запрос, имеет право видеть в Upservice — по тем же правилам, что при ручном создании пользовательского отчёта в интерфейсе.
7. При ошибке построения отчёта ИИ-сотрудник сообщает об этом в чате; отчёт в список не добавляется.
8. Ручное создание и просмотр системных и пользовательских отчётов в интерфейсе остаётся без изменений.
9. ИИ сотрудник получает права доступа на построение отчета в Superset через админку

## Examples

### Example 1

**Предусловия:** Пользователь ведёт диалог с ИИ-сотрудником в чате контакта.

**Действие:** Пользователь пишет: «Сделай отчёт по лидам за последний месяц с разбивкой по этапам воронки».

**Ожидаемый результат:** ИИ-сотрудник создаёт пользовательский отчёт. В том же чате появляется сообщение с названием отчёта и действием «Открыть отчёт». По действию открывается страница отчёта. Отчёт доступен во вкладке «Пользовательские отчёты» раздела «Отчёты».

### Example 2

**Предусловия:** Пользователь в диалоге с ИИ-сотрудником в чате задачи.

**Действие:** Пользователь пишет: «Сделай отчёт по продажам».

**Ожидаемый результат:** ИИ-сотрудник задаёт уточняющие вопросы (например, период, метрики, срез) и не создаёт отчёт, пока пользователь не уточнит параметры.
