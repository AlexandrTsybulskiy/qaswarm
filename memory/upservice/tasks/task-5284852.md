## Description

## User Story

Как пользователь Upservice,
я хочу видеть лиды контрагента отдельным табом и хранить заметки по контрагенту на его карточке,
чтобы работать с компанией в одном месте.

## Acceptance Criteria

1. На карточке контрагента (`Клиенты → Контрагенты`) доступен таб «Лиды».
2. В табе «Лиды» отображаются лиды, связанные с этим контрагентом.
3. По клику на лид в табе «Лиды» открывается карточка лида — как при переходе к лиду из CRM.
4. На карточке контрагента в левой панели доступно поле «Заметки».
5. Пользователь может ввести и сохранить текст заметки для конкретного контрагента.
6. Сохранённая заметка отображается при повторном открытии карточки этого контрагента.
7. Табы «История», «Контакты», «Сделки» и «Реквизиты» работают как сейчас.

## Examples

### Example 1. Просмотр лидов контрагента

**Предусловия:** У контрагента «ООО Ромашка» есть два лида в CRM, связанных с этой компанией, и один лид другого контрагента.

**Действие:** Пользователь открывает карточку «ООО Ромашка» и переходит на таб «Лиды».

**Ожидаемый результат:** В списке отображаются два лида «ООО Ромашка». Лид другого контрагента не показывается.

### Example 2. Переход в карточку лида

**Предусловия:** На табе «Лиды» контрагента отображается лид «Поставка оборудования».

**Действие:** Пользователь нажимает на этот лид в списке.

**Ожидаемый результат:** Открывается карточка лида «Поставка оборудования».

### Example 3. Заметка по контрагенту

**Предусловия:** У контрагента «ИП Иванов» заметка не заполнена.

**Действие:** Пользователь в поле «Заметки» вводит «Перезвонить в пятницу» и сохраняет.

**Ожидаемый результат:** При повторном открытии карточки «ИП Иванов» в поле «Заметки» отображается «Перезвонить в пятницу».
