### tc-4985417-3
title: Переключатель причины провала
action: Посмотреть блок «Конечный неуспешный статус» (пример статуса «Закрыто и нереализовано»)

status: active

### tc-4985417-4
title: Список причин при включении
action: Включить переключатель «Собирать причину провала»
expected: отображается список «Причины провала» и действие «Добавить причину».
status: active

### tc-4985417-5
title: Плейсхолдер пустой строки
action: При включённом переключателе и пустом списке открыть первую строку
expected: плейсхолдер «Кликните для ввода причины».
status: active

### tc-4985417-6
title: Добавить строку причины
action: Нажать «Добавить причину»
expected: появляется строка для ввода (на макете текст «Новая причина»); у строки есть drag handle, иконки правки и удаления.
status: active

### tc-4985417-7
title: Сохранённое значение — одна причина
action: Задать значение в списке «Причины провала»
expected: каждое сохранённое значение — одна причина перевода (пример на макете: «Не устроила цена (сделать первую общую для примера)»).
status: active

### tc-4985417-8
title: Выключить сбор причины
action: Выключить переключатель «Собирать причину провала»
expected: список «Причины провала» не показывается; перенос лида на этот статус не требует причину.
status: active

### tc-4985417-9
title: Модалка при переносе лида
action: Перенести лид на стадию, где переключатель включён
expected: открывается модальное окно с заголовком «Причина провала», иконкой закрытия, подписью поля «Причины провала», плейсхолдером «Выберите причины» и кнопкой «Отправить».
status: active

### tc-4985417-10
title: Варианты в выпадающем списке
action: Открыть выпадающий список в модалке
expected: варианты совпадают со значениями из настроек (на макете: «Причина 1», «Причина 2», «Причина 3», «Причина 4»).
status: active

### tc-4985417-11
title: Отправить выбранную причину
action: Выбрать причину и нажать «Отправить»
expected: лид переходит на целевой статус.
status: active

### tc-4985417-12

action: После успешного переноса с причиной открыть лог изменений
