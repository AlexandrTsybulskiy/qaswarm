## Cases

### tc-5199314-1
title: Ответ из Upservice без интернета
action: Пользователь спрашивает данные, доступные в Upservice в рамках его прав (например телефон контакта «ООО Ромашка»), и в базе знаний ИИ-сотрудника нет отдельной записи по этому объекту
expected: ответ содержит данные из Upservice с пометкой «Из Upservice»; поиск в интернете не выполняется; разрешение на интернет не запрашивается
status: active

### tc-5199314-2
title: Достаточно данных без поиска
action: Данных Upservice и базы знаний достаточно для ответа на запрос
expected: поиск в интернете не выполняется; разрешение на интернет не запрашивается
status: active

### tc-5199314-3
title: Запрос разрешения на интернет
action: Данных Upservice и базы знаний недостаточно для ответа, либо в запросе явно указана потребность во внешних или актуальных данных (например «Найди в интернете актуальные новости…»)
expected: ИИ-сотрудник перед обращением в интернет явно запрашивает у пользователя разрешение на поиск в интернете
status: active

### tc-5199314-4
title: Поиск после согласия
action: ИИ-сотрудник запросил разрешение на интернет-поиск, пользователь согласился
expected: выполняется поиск в интернете; фрагменты ответа из интернета помечены «Из интернета» и содержат кликабельную ссылку на источник
status: active

### tc-5199314-5
title: Отказ от интернет-поиска
action: ИИ-сотрудник запросил разрешение на интернет-поиск, пользователь отказал
expected: поиск в интернете не выполняется; ответ строится только на данных Upservice и базы знаний, если их достаточно; если недостаточно — сообщается об отсутствии данных без выдуманных фактов
status: active

### tc-5199314-6
title: Честно не нашёл информацию
action: После поиска в Upservice и (при согласии) в интернете информации нет
expected: ИИ-сотрудник сообщает, что не нашёл информацию; в ответе нет неподтверждённых фактов
status: active

### tc-5199314-7
title: Пометка Из Upservice
action: Фрагменты ответа, полученные из данных Upservice или базы знаний ИИ-сотрудника
expected: помечены «Из Upservice»
status: active

### tc-5199314-8
title: Только публичные источники
action: Поиск в интернете (после согласия)
expected: выполняется только по публичным источникам без авторизации и не включает действия, меняющие данные или состояние во внешних системах
status: active
