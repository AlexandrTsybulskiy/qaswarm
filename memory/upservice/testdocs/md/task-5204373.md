## Cases

### tc-5204373-1
title: Виджет на дашборде отображается
action: Открыть личный дашборд Web под текущим сотрудником
expected: отображается виджет с заголовком «Ждут моего ответа»
status: active

### tc-5204373-2
title: Пустое состояние виджета
action: При отсутствии сообщений, ожидающих ответа текущего пользователя, открыть личный дашборд
expected: виджет показывает пустое состояние «Сейчас никто не ждёт вашего ответа»
status: active

### tc-5204373-3
title: Персональный mention учитывается
action: Пользователь A упомянут персонально через `@mention` в чате задачи; пользователь B не упомянут; оба открывают личный дашборд
expected: сообщение есть в виджете A и отсутствует в виджете B
status: active

### tc-5204373-4
title: Mention подразделения учитывается
action: Пользователь состоит в подразделении, которое упомянули через `@mention` в сообщении
expected: сообщение появляется в виджете этого пользователя
status: active

### tc-5204373-5
title: Reply на пользователя учитывается
action: На сообщение текущего пользователя сделан Reply (в том числе в записи справочника)
expected: Reply появляется в виджете текущего пользователя
status: active

### tc-5204373-6
title: Сообщение в беседе 1:1
action: В беседе 1:1 с текущим пользователем приходит новое сообщение без `@mention`
expected: сообщение появляется в виджете
status: active

### tc-5204373-7
title: Входящее клиента по контакту
action: Текущий пользователь — ответственный за контакт; клиент отправляет входящее без `@mention` и без Reply

status: active

status: active

status: active

title: Mention неответственного

status: active

### tc-5204373-11

status: active

status: active
