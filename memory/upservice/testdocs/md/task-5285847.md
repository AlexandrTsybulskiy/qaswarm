## Cases

### tc-5285847-1
title: Отчёт из чата контакта — сообщение с «Открыть отчёт»
action: Пользователь в чате контакта с ИИ-сотрудником; запрос с однозначными параметрами («Сделай отчёт по лидам за последний месяц с разбивкой по этапам воронки»)
expected: создан **один** пользовательский отчёт; в том же чате появляется сообщение с **названием отчёта** и действием **«Открыть отчёт»**
status: active

### tc-5285847-2
title: «Открыть отчёт» открывает страницу отчёта
action: Пользователь нажимает **«Открыть отчёт»** в сообщении ИИ-сотрудника в чате
expected: открывается **страница** созданного отчёта (тот же отчёт, что создан по запросу)
status: active

### tc-5285847-3
title: Отчёт во вкладке «Пользовательские отчёты»

expected: отчёт отображается во вкладке **«Пользовательские отчёты»** раздела **«Отчёты»** workspace компании и **доступен** пользователю, сделавшему запрос
status: active

### tc-5285847-4
title: Отчёт из чата задачи — полный цикл
action: Пользователь в **чате задачи** с ИИ-сотрудником; запрос с однозначными параметрами отчёта
expected: создан один пользовательский отчёт; в чате — сообщение с названием и **«Открыть отчёт»**; отчёт доступен во вкладке **«Пользовательские отчёты»**
status: active

## Gaps

- Полный перечень типов чатов с ИИ-сотрудником не зафиксирован — проверены только чат контакта и чат задачи.
- Правила формирования названия отчёта (автогенерация, язык, длина) не описаны.
- Сценарии проверки прав доступа к данным (набор ролей, «нет доступа к сущности X») не заданы — опора на сравнение с ручным отчётом.
- Поведение при запросе отчёта по данным, к которым у пользователя нет доступа (ошибка vs частичный отчёт vs уточняющий вопрос), не описано.
- Настройка прав ИИ-сотрудника в Superset через админку — инфраструктурная зависимость; публичные API отчётов не каталогизированы.
- Структура сообщения с действием «Открыть отчёт» (кнопка, deep link, payload) не зафиксирована.
- Не описаны: таймауты построения, повторный запрос с теми же параметрами, одновременные запросы из разных чатов, локализация текстов ИИ-сотрудника.
- Платформы (Web / mobile) не указаны — мобильное поведение не задано.
