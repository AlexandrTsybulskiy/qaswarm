## Cases

### tc-5363586-1
title: Переписка видна в «Контакты и чаты»
action: К чату контакта подключён внешний канал; контакт присылает входящее сообщение
expected: сотрудник видит эту переписку в существующем чате раздела «Контакты и чаты»
status: active
tier: smoke

### tc-5363586-2
title: ИИ использует текст нового входящего
action: К чату контакта подключён внешний канал; ИИ-сотрудник имеет доступ к этому чату; контакт присылает входящее сообщение с текстом, видимое сотруднику в чате; пользователь в этом чате спрашивает ИИ-сотрудника о тексте сообщения
expected: ИИ-сотрудник использует текст этого входящего сообщения как рабочий контекст
status: active
tier: smoke

### tc-5363586-3
title: ИИ опирается на историю без нового
action: К чату контакта подключён внешний канал; в чате уже есть входящие сообщения внешнего канала, видимые сотруднику; ИИ-сотрудник имеет доступ к чату; новое сообщение сейчас не приходит; пользователь просит ИИ-сотрудника опереться на одно из уже показанных сообщений канала
expected: ИИ-сотрудник использует текст этого сообщения из истории чата как рабочий контекст
status: active

### tc-5363586-4
title: То же представление вложения для ИИ
action: К чату контакта подключён внешний канал; пришло входящее сообщение с вложением; сотруднику в чате показано определённое представление этого сообщения; ИИ-сотрудник имеет доступ к чату; пользователь обращается к ИИ-сотруднику по этому сообщению
expected: ИИ-сотрудник получает то же представление содержимого (включая вложение), которое уже показано сотруднику в чате
status: active

### tc-5363586-5
title: Без доступа сообщения чата недоступны
action: Сообщение внешнего канала видно сотруднику в чате; у ИИ-сотрудника нет доступа к этому чату; пользователь обращается к этому ИИ-сотруднику по тексту сообщения из чата
expected: сообщение этого чата этому ИИ-сотруднику недоступно
status: active
